# 公司大脑品牌图形

`logo-master.png` 为用户于 2026-11-03 选定的粉紫渐变脑形 Logo：左侧脑纹，右侧几何神经网络。经用户提供参考图，使用内置 image_gen 重绘并选定，保留透明通道。参考图与生成过程留在本地设计目录，不随安装包分发。

`scripts/prepare-brand.mjs` 从同一主图生成网页与桌面页面所需 PNG、浏览器图标、Windows 多分辨率 ICO 和 macOS ICNS。白色圆角底托属于图标排版，保证深色桌面与皮肤下的可读性。尺寸转换不重新生成或改变 Logo 图形。

修改主图后运行 `npm run build`；本地启动、桌面打包也会自动准备品牌资源。生成文件不进入源码历史，发布时由构建生成并按白名单检查。
