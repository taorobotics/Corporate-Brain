# v0.34.7 · 启动动画自动继续

## 员工端更新

- 保留未登录直接打开星球登录页的流程。公司账号验证成功并读完本机空间后，自动播放之前选定的原版技术档案启动动画，使用公司大脑的透明 Logo 和名称。
- “授予访问权限”“确认身份”两个动画阶段自动继续，显示“自动继续中，无需点击”，无需手点按钮。播完直接进入工作界面，设置中的预览也会播完自动返回。
- 保留跳过按钮和 Esc，跟随浅色、深色设置；系统要求减少动态效果时直接进入。动画资源故障不会永久挡住已验证的工作界面。
- 两个阶段仅控制动画，不代替真实账号登录，不申请、改变或扩大系统、NAS、文件夹和员工账号权限。

## 客户端与服务器更新

客户端与服务器版本均为 0.34.7。员工页面和本次动画资源由公司服务器提供，管理员须同步服务器更新包；仅安装桌面客户端不会替换服务器网页。Windows 可在客户端检查更新、后台安装并自动重启；Mac 使用对应芯片的 DMG。

Mac mini 为主要部署目标。部署前一致性备份原数据库、密钥和项目配置；保留账号、部门、NAS、技能、模型配置及员工本机对话。三平台安装包同步到 Mac mini 和云端备用更新源。
