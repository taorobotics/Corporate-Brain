# v0.2.10

## 员工端更新

- 员工打开“模型与服务”页面时会重新读取公司模型连接，避免管理员新增连接后已打开的客户端仍显示“还没有可用的模型连接”。
- 员工端窗口从后台切回前台时会再次刷新模型授权，新增或调整部门授权后可直接看到当前可用模型。

## 管理后台更新

- “添加公司模型连接”弹窗打开时会重新读取部门列表，确保最新部门授权出现在选择框中。
- 部门授权列表增加空数据提示，并限制横向溢出，避免部门名称或列表布局导致复选框与文字不可见。

## 验证范围

- `npm run version:check`
- `npm test`（18 项通过）
- `npm run build`
- 已通过公司服务器 API 验证：管理员和员工均能读取已保存的 LinoRoute 公司连接；员工授权返回包含该连接。

## 部署说明

- 客户端页面与业务接口一起更新服务器包；现有 `.data`、账号、部门和模型密钥保持不变。
- Windows 与 macOS 安装包由本版本 GitHub Actions 原生构建并在 Release 中提供。当前发行包仍按项目签名政策标注签名状态。
