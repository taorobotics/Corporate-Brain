# v0.2.6

## Windows 安装器空间检查修复

- 修复安装位置页在 C 盘临时目录可用空间不足时直接中止的问题。
- 临时目录预留从程序所需空间的 4 倍调整为约 2 倍，覆盖压缩包、暂存副本和安装过程余量。
- 空间不足时显示临时目录当前可用空间和预计需要空间，明确提示需要清理的是系统临时目录所在磁盘。
- 保留 D 盘优先、安装目录空间检查、取消安全性、升级和个人记录保留逻辑。

## 验证

- 本机 UI 验证覆盖欢迎页、安装位置页和取消确认。
- 发布时继续执行 Windows 真实安装、升级、卸载和个人记录保留检查，以及 macOS 双架构和服务器包检查。
- Windows 仍为未签名测试包，macOS 仍为 ad-hoc 测试包。
