# v0.24.1 · 米白对话排版

本候选版未公开发布。跨平台复验发现布局变化时的自动滚动问题，米白排版与后续供应商模型菜单、修复统一由 v0.25.0 交付；保留原候选标签，不覆盖安装包。

## 员工端更新

- 参考宽松、清晰的对话阅读布局，默认 Claude 浅色皮肤保留米白背景，输入框采用暖白色与柔和边框。
- AI 回复与客户端界面统一使用现有无衬线字体，移除默认皮肤回复区单独的衬线字形。大窗口正文为 18px，常规窗口 17px，窄窗口 16px。
- 调整对话列宽、行距、段落、标题和列表留白，改善长内容阅读；表格与代码保留独立排版和横向滚动。
- 用户消息采用圆角气泡，输入框与对话列对齐，侧栏导航适度放大。保留当前皮肤选择、深色模式、Grok-ball、真实处理过程和消息操作。

## 管理员与服务器更新

本次为界面更新，无数据库结构变更。客户端从公司服务器加载界面，需要部署本版服务器包，连接该服务器的客户端重新打开即可加载新版页面。更新前先停止服务并一致性备份数据库、`secrets.key` 和部署配置，在新目录解压服务器包，安装锁定依赖并沿用原数据目录及 HTTPS 设置启动。

安装包和服务器分别更新。Windows 可在客户端检查更新并点击“安装”，后台更新后重新打开；Mac 使用对应架构 DMG 替换。仅重新安装客户端不会替换公司服务器网页。

## 检查与边界

原生客户端使用隔离示例对话检查字体、字号、米白背景、浅深色截图和窄窗口溢出；同时运行原有自动滚动、表格、代码、个人模型与账号隔离验收。Windows、Apple 芯片 Mac、Intel Mac 的构建和安装检查以 Release 随附的真实报告为准。排版截图属于测试示例，不包含员工对话。

原创代码采用 MIT，第三方保留原许可；隐私与签名政策随客户端和服务器分发。安装包和源码不含公司数据库、密钥、员工聊天或内部技能。Windows 未获可信代码签名，Mac 使用 ad-hoc 签名且未做 Apple 公证。通过 `SHA256SUMS.txt` 核对下载文件。
