# v0.20.0 对话多技能调用

## 员工端更新

- 对话输入框的“技能”按钮向上展开当前账号在本机已安装的技能，无需离开对话。支持搜索名称和用途，保留技能中心入口。
- 默认“自动调用已安装技能”：AI 按本轮需求选择相关技能，也可以组合多个；不把全部已安装技能强行用于每条消息。
- 可以手动同时选择最多 16 个技能，选中后显示可移除标签。选择会在当前账号保存；移除全部标签表示本轮不使用技能，可随时重新开启自动。
- 对话、图片创作、代码与视频制作均传递实际选用的技能。处理进度显示本轮选用的技能名称。
- 浅色、深色、窄窗口与键盘操作适配。各账号的安装列表与选择相互隔离；已停用、撤权或缺少所需工具的技能不能继续调用。

## 客户端与服务器更新

Mac mini 为公司主要服务器。本次界面和调用逻辑由服务器包提供，管理员需先一致性备份，再更新服务端代码和网页，继续使用原数据库、secrets.key、NAS、模型连接和 HTTPS 设置。已连接该服务器的客户端重新加载后可使用；新版安装包另行递增为 0.20.0，原有更新入口继续使用。

Windows 安装包沿用原目录后台更新和自动重启流程；Mac 使用对应架构 DMG。功能不增加模型密钥填写要求。技能仍只使用已有文件、网络和工作区权限；第三方安装脚本不会自动执行。对话的导入技能资料交给 DSH 文件工具；图片与代码/视频模型接收经完整性校验、有长度限制的文本参考，二进制素材和依赖不会因此自动变为可执行工具。

## 检查范围与发布状态

新增技能授权、自动选择、组合正文、参考资料完整性和长度边界检查，并覆盖实际聊天、图片、代码任务接口和其他部门权限。DSH 检查同时导入两个独立技能目录及中途失败后的清理。真实 Electron 窗口检查上拉定位、搜索、多选、标签移除、默认自动、请求中的多个技能、重启保存、账号隔离、深色及窄屏。

真实检查结果、安装包摘要、Mac mini 部署和分发状态在本版交付报告记录。正式 Release 仍要求 Windows 与两种 Mac 的原生构建和相应验收全部通过；构建费用或平台检查受阻时保留草稿，不把局域网分发描述为完整公开发行。
