# v0.33.3 · 协作桌面与云雾蓝紫

## 员工端更新

- 将已确认的「协作桌面＋云雾蓝紫」界面落实到真实客户端：左侧功能栏与项目会话列表分开，浅蓝紫渐变、清晰分组和左下角更新入口保持一致。
- 统一使用随包提供的 Noto Sans SC 中文和 Inter 英文、数字字体，调整标题、正文、表格和输入框的字号与间距；去除对话标题下的横线。
- 处理状态收成一行，真实思考与工具活动仍可展开。复制、点赞、反馈和分享保持可用，模型与 Token 用量集中到「回答详情」。
- 输入区直接显示供应商与当前模型，保留已安装技能多选、项目权限、停止与补充要求，自动调用不再重复展示多个模式标签。
- 成果文件改为紧凑卡片，提供「打开文件夹」及受支持格式的实际预览入口。文件读取与账号隔离继续通过原有桌面授权校验。
- 原默认 Claude 外观一次性升级为云雾蓝紫；其他已选皮肤、深色偏好、项目和对话保留。仍可在皮肤中心选择 Claude 等其他皮肤。

## 客户端与服务器更新

管理员备份并部署本版服务器更新包后，连接该服务的员工重新打开客户端即可加载新界面。完整字体在公司服务和桌面安装包内提供，不依赖外部字体站点；桌面安装包及自动更新源同步为 0.33.3。仅升级安装包不会替换公司服务器业务。

Windows 使用原安装目录更新；Mac 选择对应架构 DMG。账号、部门、模型密钥、NAS 权限及个人文件不包含在公开更新包中。

## 验证范围与分发状态

本版覆盖外观偏好迁移与保留、字体加载、明暗模式、窄窗口、真实项目与并行对话、模型供应商选择、技能多选、复制与反馈、文件快捷入口及安装更新。各平台真实构建、桌面和安装检查记录随正式 Release 提供。

原创代码采用 MIT，第三方组件与字体保留原许可；不包含数据库、密钥、员工聊天、NAS 正文或内部技能。Windows 尚未做可信代码签名；Mac 为 ad-hoc 签名，未做 Apple 公证。
