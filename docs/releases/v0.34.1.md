# v0.34.1 · 星球动态登录页

## 员工端更新

- 登录页采用已确认的暖白双栏设计，统一 Inter 与 Noto Sans SC 字体、账号输入、密码输入和登录按钮的排版。
- 左侧为原创玻璃星球、金属轨道和卫星的实时三维视觉，支持轻微鼠标跟随。星球画面不放置公司标志或文字，公司标志保留在页头。
- 支持浅色与深色切换、手动暂停动效；系统要求减少动态效果或窗口隐藏时停止动画。窄窗口隐藏装饰区，显卡不可用或绘图上下文丢失时显示原创静态星球，保留可用的登录表单。
- 密码可显示或隐藏，开启大写锁定时提示；忘记密码提供联系公司管理员的说明。保留实际账号验证、首位管理员初始化、窗口控制和隐私与许可入口。
- 原有客户端启动动画及进入工作台的流程保留。登录页不包含演示账号、模拟登录或新的注册入口。

## 客户端与服务器更新

客户端与服务器版本均为 0.34.1。员工界面由公司服务器提供，因此需更新服务器包才能看到新登录页；仅安装新版客户端不会替换服务器上的网页。

Mac mini 是本次主要部署目标。服务器包包含编译后的网页与锁定依赖，新版新增 Three.js 依赖，须在新的版本目录运行 `npm ci --include=dev`，不能直接复用旧版依赖目录。部署前一致性备份数据库、加密密钥及本项目配置；继续使用原有数据库与密钥，保留账号、部门、NAS、技能、模型配置及员工本机对话。

三平台安装包及校验文件通过 GitHub Releases 和公司更新源分发。Windows 已安装用户可从客户端更新入口后台升级并自动重启；Mac 使用相应架构的 DMG 更新。

## 验证范围与许可

本机 206 项程序测试、8 项 NAS 测试、完整桌面交互、个人资料与生产任务流程检查通过。新增真实 Electron 登录页验收，覆盖真实接口拒绝错误密码、成功登录、深浅色、390px 窄窗口、密码可见性和管理员帮助；在本机实际 WebGL 下验证画面帧变化、指针交互、手动暂停、系统减少动态效果、隐藏窗口暂停、登录后资源释放及绘图上下文丢失后的静态显示。

三维模块在启动动画结束后按需加载，不读取账号表单，不请求远程纹理、外部场景或遥测服务。动画限制最高 30 帧/秒和像素比 1.5，进入工作台后释放绘图资源。三平台正式构建与原生安装、升级、卸载和分发检查以 Release 附带的真实平台记录为准；没有 WebGL 的运行环境据实记录静态显示，不宣称已验证硬件三维效果。

原创代码与星球视觉采用 MIT。Three.js 固定为 0.187.0，保留 MIT 许可及第三方声明；没有嵌入 Vibrant 或 Spline 的专有素材或在线场景。Windows 尚未取得可信代码签名；Mac 使用 ad-hoc 签名，未经过 Apple 公证。
