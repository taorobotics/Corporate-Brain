# 公司大脑 0.18.0

## 员工端更新

- 输入框统一为 AI 自动对话入口，移除任务类型和 DSH 模式两个选择菜单。直接描述需求，系统按对话上下文选择问答分析、图片创作、视频制作或代码文件，并在内部选择工具配置。
- 图片创作自动调用员工获准使用的图片服务；读图、文档和视频内容分析仍使用对话能力。需要时自动切换到已授权的识图模型。
- 视频与代码任务在当前对话显示制作和本地保存进度，无须跳转页面。首次制作只需选择此电脑的成果保存文件夹；Mac mini 完成后回传源代码、原始素材和成片，本机完整校验后立即清理服务器任务文件。
- 保留模型选择、技能入口和工作区权限。自动调度不能扩大部门权限；仅可查看时不创建生成任务。缺少图片服务、原始素材或本机目录时显示明确提示。

## 客户端与服务器更新

本次调度接口和界面随服务器包更新，需配套部署。已有支持制作中心的客户端重新打开后即可使用统一入口；本版安装包用于新设备与版本同步。旧版 API 和本机历史继续兼容，不清空员工数据。

更新 Mac mini 前一致性备份，核对账号、部门、NAS、技能、模型设置和密钥保持。完整平台构建、安装检查及资源校验通过后才公开正式 GitHub Release，局域网交付另行记录。
