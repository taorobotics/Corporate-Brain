# v0.19.0 · 对话中的自动制作工作流

## 员工端更新

- 视频与代码直接在 AI 对话内执行，移除独立“制作中心”入口和提交表单。
- 显示五步真实执行进度、模型制定的计划、失败环节、原地重试、停止任务和成果文件列表。提交任务不会提前显示制作完成。
- 修复 DeepSeek Flash 默认思考耗尽输出额度、动画代码截断导致失败的问题；检查截断、JSON 与动画语法，代码或渲染失败时最多自动修复一次。
- 新桌面客户端支持在原对话预览已保存的本机 MP4 与源码文本；文件不会作为网页或脚本运行。
- 成果、素材、执行计划与源代码全部回传员工电脑，完整校验并确认后清理 Mac mini 任务目录。

## 客户端与服务器更新

本次包含网页、服务和桌面桥接变更。管理员先备份并更新服务器包；已有客户端重新打开后可获得对话工作流、失败重试和自动保存。要在对话内预览本机视频或源码，还需安装 0.19.0 客户端；旧客户端继续提供“打开成果文件夹”。本机记录不迁移到服务器。

## 真实检查与发布状态

本地 74 项 Node 测试、5 项 Python 测试、Windows 完整桌面 37 项、离线启动与对话工作流专项通过。专项覆盖生成时保存步骤仍为待执行、一次自动修复后失败、原地重试恢复、真实本机源码预览、所有文件 SHA-256 校验和服务器清理。Windows 本机视频渲染未通过，本次视频服务器为 Mac mini，另行在 Mac 验收。完整 Windows 安装生命周期、Mac arm64 / Mac x64 原生检查与安装资源齐备前，只保留 GitHub 草稿，不设置为最新公开版本。交付记录随部署补充。

Windows 尚无可信代码签名；Mac 使用 ad-hoc 签名，未公证。开源代码采用 MIT，第三方许可和隐私说明随包提供。本次不启用 Remotion；生产图片生成仍依赖管理员配置可用的图片连接。
