# v0.20.1 大目录读取修复

## 员工端更新

- 修复读取较大本地项目后，对话立即出现 `Too big: expected string to have <=2000000 characters` 的问题。
- 目录资料使用统一的文字预算，保留扫描返回的文件清单，优先提供 README、项目配置和入口代码；单个大文件及整批正文均有节选上限。
- 对话处理进度显示本次目录读取结果，资料明确标注节选、未读取的正文、扫描限制及未发送的图片，便于继续指定子目录或具体文件分析。
- 目录图片遵守手动附件剩余位置和画面总量限制，长文件名不会再触发附件名称校验失败。
- 客户端与服务器同步校验附件文字上限，超限时提供中文处理建议。代码和视频制作也使用相同的目录资料整理与范围说明。

## 客户端与服务器更新

本次修复由服务器提供的网页和业务服务生效。管理员需一致性备份后更新 Mac mini 的服务器代码与网页，保留原数据库、模型密钥、NAS、技能、员工数据和 HTTPS 配置。已连接该服务器的桌面客户端重新加载后即可获得目录读取修复，不必等待安装新版客户端。安装包版本另行递增至 0.20.1，继续使用已有更新入口；Windows 沿用原安装目录后台更新，Mac 通过对应架构 DMG 替换。

本次没有扩大原生文件扫描权限、范围或字节上限。模型只收到实际提供的文字和图片，不能直接读取员工电脑，也不能把节选视为完整项目。

## 检查与发布

本版增加多兆字节目录、中文大文件、单文件及整批节选、说明文档优先、长名称、空目录和图片预算回归检查。实际聊天 HTTP 接口验证原始超限请求在模型调用前被中文错误拒绝，整理后的目录正常到达合成模型。真实 Electron 检查使用独立临时项目、原生目录读取和实际路由/聊天接口，不调用公司付费模型。

最终检查、部署、安装包摘要及发布阻塞情况在本版交付记录中填写。正式 Release 仍需所有平台构建与检查齐备才公开；局域网分发与完整正式发布分别记录。
