# v0.23.0 · 对话中的图片生成技能

## 员工端更新

- 图片 API 自动成为公司图片技能，出现在技能中心和技能菜单中，按部门权限即可使用，无需重复安装或填写密钥。
- 对话保持选择聊天模型；直接提出“写介绍并生成配图”，文字和图片在同一条回复中完成，可与其他已安装技能组合使用。
- 普通问答和图片分析不会因为选择了图片技能而自动出图；“使用图片技能”保留原聊天模型。
- 文字先显示，出图时显示实际技能运行状态；失败保留已输出文字，停止操作会取消未完成的图片请求。文字与图片一并保存在员工本机对话中。
- Windows 本地记录遇到短暂文件占用时自动重试保存，保留原记录快照。

## 管理员与服务器更新

在“模型与服务 → 自定义配置”中添加或编辑服务，将需要的模型用途设为“图片生成技能”，保存后自动生效。现有图片连接也会自动成为技能。接口需支持 OpenAI 兼容 `/images/generations` 并返回 `data[0].b64_json`；当前每轮一张 PNG/JPEG/WebP，最多 20 MB，不包含图片编辑和 URL 下载适配。密钥只保存在服务器，停用或撤销授权同步到技能。

本次界面与业务代码由服务器包交付。服务器管理员先停止并一致性备份数据库、密钥和配置，将服务器包解压到新目录，安装锁定依赖，沿用原数据目录和 HTTPS 配置后启动并检查健康状态。不要覆盖公司数据库或密钥。员工客户端安装包与服务器分别更新；Windows 可在客户端检查更新并点击“安装”，Mac 使用对应架构 DMG 替换。

## 检查与边界

本次新增隔离上游测试覆盖技能派生、文字与图片共同响应、大图流传输、权限隔离、授权撤回、普通聊天不出图、失败与取消；原生客户端验收覆盖技能中心、模型选择保持、同条回复、本地保存与重载。发布工作流在 Windows x64、Mac arm64/x64 执行完整检查，真实检查记录随 Release 分发。隔离测试不消耗真实模型额度，不代表所有服务商或套餐均已实际生成。

仅提供 MIT 原创代码及保留原许可的依赖，不包含公司密钥、数据库、员工聊天或内部技能。隐私说明随客户端与服务器分发。Windows 尚无可信代码签名；Mac 为 ad-hoc 签名，未做 Apple 公证。下载后可使用 SHA256SUMS.txt 校验安装与服务器包。
