# 公司大脑 0.17.0

## 员工端更新

- 新增制作中心：使用已授权对话模型生成代码文件或 Canvas 动画视频，由公司 Mac mini 排队处理。
- 设置中选择成果保存位置。代码、原始素材和 MP4 完整回传、校验落盘后，服务器立即清理对应任务。
- 增加制作进度、断线恢复、失败重试、取消清理及“我的作品”本地文件夹入口。
- 同账号多台电脑分别接收各自提交的任务；本地文件已修改时停止自动覆盖。
- 修复桌面本地状态未写入工作区列表的问题。

## 客户端与服务器更新

员工自动保存功能需要本版 Windows x64 或 macOS 客户端，旧客户端会显示升级提示。服务器也需更新到本版并在项目目录安装渲染依赖，保留原数据库、密钥、NAS 与 HTTPS 配置。更新服务器网页不会自动增加旧客户端的原生文件能力。

渲染方案采用 Canvas + Chromium + 独立 FFmpeg，不启用 Remotion。代码生成消耗现有模型额度，视频编码不调用收费渲染服务。详见 [制作中心说明](../PRODUCTION.md)。
