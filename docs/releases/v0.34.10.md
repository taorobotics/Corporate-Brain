# v0.34.10 · 移除启动动画的跳过按钮

## 员工端更新

- 移除启动动画右上角的“跳过动画 / Esc”按钮，让动画画面保持完整。
- 登录后的浅色、深色启动动画和设置中的动画预览统一生效，播放结束后自动进入工作界面或返回设置。
- 保留键盘 Esc 退出、系统减少动态效果偏好和动画异常时自动退出的保护。

## 客户端与服务器更新

客户端及服务器版本均为 0.34.10。该界面由公司服务器提供；Mac mini 更新服务器包后，员工重新进入或预览动画即可看到变化。新版客户端安装包和公司更新源一并交付，Windows 沿用原安装目录更新，Mac 使用对应架构 DMG。

部署前一致性备份公司数据、密钥和配置，使用独立版本目录，不覆盖员工记录或 NAS 原文件。

## 验证与许可

修正启动验收脚本的时序：页面已就绪后，分别等待测试图片请求真正开始再检查其仍在加载。遮罩退出耗时仍在等待图片请求之前测量，保留原有时间、单次导航和资源未完成检查。

本版检查浅色、深色的真实登录后自动播放及设置预览，确认没有跳过按钮，自动完成、Esc 退出、减少动态效果和异常资源恢复仍可使用。正式发布须通过 Windows x64、Mac arm64、Mac x64 和公司服务器包检查，安装包、摘要及真实检查记录随 Release 提供。
