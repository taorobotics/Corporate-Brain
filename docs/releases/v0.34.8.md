# v0.34.8 · 修复连接页遮挡登录界面

## 员工端更新

- 修复登录页已加载却一直停在“正在连接公司工作空间”的问题。连接遮罩覆盖窗口时，浏览器可能暂停后台页面的绘制回调；本版根据页面真实内容就绪退出遮罩，解除相互等待。
- 正常窗口、被遮挡和最小化状态下均可完成连接，不必等待重试，不再重复加载已经可用的页面。较慢的图片或字体仍可继续加载。
- 未登录继续直接进入登录页，成功登录后保留原版自动启动动画。账号验证、HTTPS 证书验证和公司原有权限保持有效。

## 客户端与服务器更新

客户端与服务器版本均为 0.34.8。本次修复位于客户端本地启动层，需要安装新版客户端；仅更新服务器无法替换旧客户端的启动遮罩。Windows 可以安装本版安装包，原安装目录和本机记录保留；Mac 使用相应架构 DMG。公司服务器包与 Mac mini 安装包更新源同时交付，部署前备份原数据、密钥与配置。

## 验证与许可

使用已安装的 0.34.7 正常窗口复现：登录页已加载完成，主页面被标记为隐藏，但连接遮罩持续等待。相同 Mac mini、相同代理设置下，修复后的正常客户端约 1.4 秒完成交接。

新增实际安装包的正常运行模式检查，不启用离屏渲染或强制后台绘制；覆盖普通窗口及真实最小化窗口、原生遮罩退出、单次导航以及图片未完成时继续进入。Windows、Mac arm64、Mac x64 的平台检查记录均须包含该项结果；原有登录、自动动画、桌面交互和原生安装升级检查继续执行。
