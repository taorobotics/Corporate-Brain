# v0.1.1 公司大脑 · 下拉菜单优化

本次为小更新，由 v0.1.0 递增到 v0.1.1，包含最新客户端及公司服务器更新包。

## 更新内容

- 员工端、管理后台的 14 处选择框，以及顶部、账号菜单统一为圆角浮层、图标、勾选和状态说明，沿用 Marvis 字体与暖白配色。
- 对话底部菜单优先向上展开，支持键盘导航、Esc、焦点恢复、深色外观和窗口边界调整；弹窗中的下拉菜单不会被裁切。
- 模型未配置时提供说明和真实配置入口，按任务类型筛选可用模型，排除已停用连接，保留个人选择。
- 新增持续发版规则与统一流水线，每批完成的更新都递增版本、打包、检查并发布到 Releases。

## 下载与更新

在 Assets 中选择：Windows 用 Setup-x64.exe；Apple 芯片 Mac 用 macOS-arm64.dmg；Intel Mac 用 macOS-x64.dmg。Mac 打开 DMG，将“公司大脑”拖入应用程序。

**本次界面更新需要同步更新公司服务器。** 管理员使用 Corporate-Brain-Server-0.1.1.zip 更新服务；桌面安装包本身不替换公司服务器页面。更新前停止服务并备份公司 .data 及密钥文件，在新应用目录安装依赖，保持原数据库路径和 HTTPS 配置，再启动服务。完整步骤见 docs/RELEASE-POLICY.md 与 docs/DEPLOYMENT.md。

员工本地对话和草稿仍保存在各自电脑，服务器更新包不含员工记录、公司数据库、预设账号或模型密钥。当前手动下载安装升级，尚无客户端自动更新。

## 验证与限制

发版流程对每个平台执行版本一致性检查、生产构建、9 项后端检查和真实 Electron 桌面检查。Windows 桌面检查 20 项，Mac 不包含 Windows 外角状态检查；随包 JSON 记录各自真实结果。安装包通过客户端文件白名单、版本与 SHA-256 复核，Mac 另检查磁盘映像、架构、ad-hoc 签名及实际打包程序首次启动。

Windows 尚未做可信代码签名；Mac 仅有 ad-hoc 签名，尚无 Apple Developer ID 签名或公证，下载后可能显示系统安全提示。员工独立设备的安装、升级、卸载和 Mac 文件授权仍待完整验收。

真实模型与视频生成、NAS 知识检索和完整 Agent 执行仍按开发状态推进，不因本次界面优化而视为已完成。仓库为私有，下载需要相应 GitHub 权限。
