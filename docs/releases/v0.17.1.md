# 公司大脑 0.17.1

## 员工端更新

- 启用选定的粉紫渐变脑形 Logo，统一员工侧栏、管理后台、登录、启动动画、对话欢迎页和公司连接页。
- 统一浏览器图标、桌面窗口、Windows 安装与卸载图标、macOS 应用图标；小图标按各尺寸生成，深浅色皮肤均保留原色与白色底托。
- 品牌资源随客户端安装，在断网启动时也能显示，不增加外部图片请求。

## 客户端与服务器更新

服务器网页更新后即可显示平台新 Logo；系统图标、原生启动页与安装向导需要安装本版客户端。Mac mini 继续作为主要公司服务器，保留原账号、部门、NAS、技能、模型配置与员工本机记录。
