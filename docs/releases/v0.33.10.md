# v0.33.10 · 侧栏新增最近对话

## 员工端更新

- 左侧“项目”下方新增“最近”对话列表，汇总本机所有项目的对话，按最后一次消息时间排序；再次继续旧对话后会排到前面。没有消息的对话按创建时间排序。
- 点击最近对话直接回到原对话，并切换到它所属的项目。收起项目不会隐藏最近对话，当前对话有选中标记，鼠标停留可查看完整标题和项目名称。
- 项目列表与最近对话分别滚动，保留搜索项目、搜索对话和新建项目功能；提供无对话、搜索无结果提示，适配深色主题及窄窗口。

## 客户端与服务器更新

客户端安装包与服务器包均为 0.33.10。界面由公司服务器加载，管理员须部署本版服务器包才能显示最近对话；只更新安装包不会替换服务器网页。Mac mini 为本公司主要部署目标，安装包与更新源一并同步，云端备用安装包镜像继续分发。

部署前停止本项目服务并一致性备份数据、密钥和配置。本版只读取原有本机对话的时间和项目归属，不迁移或重写聊天记录，不改变账号、部门、NAS、模型配置及权限。

## 验收与许可

检查覆盖跨项目最近活动排序、创建时间兜底、原数组顺序保留、项目收起、搜索与空状态、打开原对话及项目归属、刷新恢复、独立滚动及实际深色窄窗口。正式 Release 随附三平台安装包、服务器包、SHA-256 和真实检查记录。

原创代码采用 MIT，第三方许可与隐私说明随包保留。Windows 尚未可信签名；Mac 为 ad-hoc 签名、未公证。

本地生产构建、198 项 Node 测试、8 项 NAS 协议测试和 64 项完整桌面交互检查通过。最近对话以跨项目及长列表的隔离记录验收，覆盖排序、搜索、跳转、刷新、空状态、标题文本安全和真实深色窄窗口，不调用公司模型或读取员工真实记录。
