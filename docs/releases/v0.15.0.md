# v0.15.0 · 文档与视频画面分析

## 员工端更新

- 对话“添加文件”支持 Word DOC / DOCX、PDF、Excel XLSX、PPTX、文本、字幕、图片和短视频；支持拖放、多选及粘贴图片。
- 显示读取进度，支持取消；点击附件查看提取文字、PDF 页码或视频时间点。附件单独发送、历史恢复和继续追问可用。
- 视频提取最多 8 张画面供视觉模型分析，不读取声音，不代表逐帧理解。扫描 PDF 最多附带 8 页画面，超过范围会明确提示。含画面时使用支持视觉的模型，DeepSeek 官方请选择 Flash。
- Word 不再只按图片上传；大文件、加密、损坏或不支持的格式会给出明确提示。具体格式与读取边界见 `docs/ATTACHMENTS.md`。

## 管理与部署

公司服务新增登录保护的 Office 临时解析，不保存原文件，不执行宏或外部引用。PDF、图片和视频画面在员工客户端处理，发送后才把提取结果交给模型。员工本机聊天、账号、模型、技能和 NAS 权限保留。

需要同步服务器包中的网页、服务代码与锁定依赖，构建时生成 PDF.js 字体和字符映射。旧客户端连接更新后的 Mac mini 即可使用新界面；Windows 与 Apple 芯片 Mac 的新安装包通过公司局域网更新入口下载并校验，员工确认安装。服务器仍由管理员备份后单独升级。

GitHub 按用户此前要求保持暂停，本次为私有局域网交付。Windows 未可信签名；Mac 为 ad-hoc 签名且未公证。未生成 Intel Mac 新包，未执行员工电脑覆盖安装或卸载；实际验收记录与包一起交付，不能称为完整公开 Release。
