# v0.8.0

## 员工端更新

- 新增「设置 → 皮肤中心」，内置 DSH 皮肤库的 62 款选款，支持搜索、分类、浅色/深色预览、全窗试用、取消及保存。
- 默认改为 Claude：暖米色与珊瑚橙，深色为暖黑；带自托管衬线正文与代码字体。旧账号首次升级自动采用 Claude，保留原来的深浅色偏好。
- 选择按公司地址和员工账号保存在此设备；重启恢复，切换账号互不影响。可随时恢复默认 Claude。
- 8 款包含获准分发的原作背景，Claude 适配字体与配色；其余 53 款明确标注「配色适配」，采用本项目独立界面，不包含原作的受限插画、角色或专属动画。选款不是原站插件运行环境，不执行第三方脚本。

## 管理与部署更新

- 网页和皮肤资源随服务器更新包交付。管理员备份 `.data` 与环境配置后，部署 `Corporate-Brain-Server-0.8.0.zip`，继续使用现有数据库和密钥。
- 已安装客户端从公司服务器加载界面：服务器更新后重新打开客户端即可看到皮肤中心。安装包版本更新仍通过客户端更新入口或手动安装完成；仅安装新版客户端不会替换公司服务器页面。
- 皮肤背景与字体自托管，不依赖外部图床、不放宽安全策略。第三方来源、固定版本与许可随客户端和服务器包保留。

## 验证范围

- 本地后端与共享逻辑测试、TypeScript 检查和生产构建。
- 真实 Electron 客户端：62 款列表、搜索、试用不写入偏好、取消/Escape、带背景的深色模式、保存、重载、恢复 Claude、账号隔离、900px 窗口。
- 62 款 × 2 种明暗的文字与主按钮对比度、图片路径及本地文件检查。
- 实际结果记录见 `artifacts/skin-verification.json` 和 `artifacts/desktop-verification.json`。完整跨平台发布仍须 Desktop release 工作流全部通过后方可公开。
