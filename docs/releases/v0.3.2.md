# v0.3.2

## DeepSeek 模型同步

- 启用 `DEEPSEEK_SYNC_MODELS=1` 后，服务器启动会自动同步两个公司模型到管理后台：`DeepSeek Flash`（`deepseek-flash`）和 `DeepSeek Pro`（`deepseek-v4-pro`）。
- 两个模型使用同一个 `DEEPSEEK_API_KEY`，密钥写入服务器加密连接字段，不进入客户端、Release 或日志。
- `DEEPSEEK_CHAT_BASE_URL` 可覆盖聊天 API 地址，默认 `https://api.deepseek.com/v1`；自动同步连接按全公司范围创建，需部门限制时可关闭自动同步后手动配置。

## 验证范围

- `npm test`（22 项通过）
- DeepSeek 实际 Key 验证：模型列表返回 `deepseek-flash`（text/image）与 `deepseek-v4-pro`，Search API 返回成功结果；密钥未输出。

## 部署说明

- 使用 [DeepSeek 配置与部署说明](../DEEPSEEK-SETUP.md) 中的本地 env 文件；服务器更新后重启，两个模型会出现在管理后台。
- Windows x64、macOS arm64/x64 安装包、公司服务器更新包和 SHA-256 校验文件由本版本 GitHub Release 提供。
