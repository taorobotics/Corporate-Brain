# v0.2.1 公司大脑开源准备测试版

## 员工端更新

- 新增“隐私与许可”入口，登录前、帮助菜单与离线公司连接页均可查看隐私政策、MIT、第三方许可和签名政策。
- 开源通用程序，真实账号、聊天、内部 Skills、密钥与公司资料仍保存在原有设备或公司部署中，不进入源码或安装包。
- 增加公开仓库更新源模式；维护者公开仓库后，由管理员启用，员工继续使用公司账号。

## 开源、签名与下载

原创代码采用 MIT，补充第三方许可与锁定依赖清单、隐私说明、Code signing policy、安全报告和贡献规则、CODEOWNERS、申请材料及开源准备检查。Windows 可执行文件产品名称与版本已按项目设置，安装和应用包包含许可材料；Mac 包保留 Electron/Chromium 上游声明。

本版仍未获 SignPath Foundation 批准，Windows 未签名；Mac 仍为 ad-hoc，无 Apple Developer ID 或公证。没有假签名或已获批声明。公开源码不自动取得可信签名，需维护者确认公开、开启 MFA、申请服务并通过审核；正式签名后须验签和计算新摘要，用新版本分发，不覆盖本版。

Assets 包含 Windows x64 EXE、Mac arm64/x64 DMG、服务器 ZIP、SHA256SUMS.txt 和真实报告。公司服务先停止并一致性备份 .data（含 secrets.key）和部署配置，将服务器包解压到新的目录，npm ci --include=dev，继续使用原 BRAIN_DATABASE、密钥、HTTPS 与 APP_ORIGIN 等设置后 npm start。不要清空公司或员工数据。

公开仓库后，服务器可设置 BRAIN_UPDATE_SOURCE=public，省去 GitHub token；默认私有模式保持原有服务器端令牌读取。公司登录、部门权限和内部 Skill 授权保持有效。公开仓库不会自动公开公司服务器。

## 验证范围

本次运行 18 项测试、生产构建、Windows 22 项 / Mac 21 项原生桌面检查及实际打包检查，包括隐私和许可入口、允许文件清单、许可文本、产品版本与元数据、Mac DMG 挂载和实际程序启动。Gitleaks v8.30.1（固定摘要）对全部可达 Git 历史做脱敏扫描，实际范围见 artifacts/open-source-readiness.json；这不等于独立漏洞审计或签名服务承诺接收。

既有 Release 不替换；首次开源需维护者审阅历史、素材与旧包。员工物理设备上的升级、系统授权、卸载和正式签名仍需分别验收。更多信息见 README 的 Code signing policy、隐私说明和 OPEN-SOURCE-READINESS.md。
