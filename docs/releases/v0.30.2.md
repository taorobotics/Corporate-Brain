# v0.30.2 · 独立项目与左侧项目列表

## 员工端更新

- 将本地“工作区”“新建工作区”“工作区权限”统一为“项目”“新建项目”“项目权限”，默认名称改为“默认项目”；已有自定义名称保留。
- 修复新建时选择相同文件夹只会切回旧项目的问题。每次确认文件夹都会追加一个独立项目，相同名称自动增加编号，原项目、对话和权限不被覆盖。选择的文件夹仍是该项目使用的本地目录；同一个目录可以被不同项目引用。
- 左侧分别列出项目及其对话，支持展开、收起、搜索、切换和在指定项目中开始新对话。创建或切换项目会清除旧搜索条件，避免新项目被过滤隐藏。
- 项目页与左侧使用同一份项目列表。旧版项目卡片自动接入这份列表，不重复迁移、不删除已有项目。点击项目卡片会进入对应项目的新对话，后续消息归属该项目。
- 新对话页顶部显示当前项目名称；进入已有对话后继续显示对话标题，本地完整路径仍不会常驻对话界面。

## 客户端与服务器更新

本次修复主要位于服务器提供的员工界面。Mac mini 备份并部署本版服务器包后，已有客户端重新打开即可使用；桌面版本同步到 0.30.2。Windows 可从左下角检查更新、下载校验后安装并自动重启，Mac 使用对应架构 DMG。只重新安装桌面程序不会替换服务器。

项目和对话仍按员工账号保存在员工本机。迁移保留原项目标识、目录、权限和已有对话归属，旧项目卡片的原始备份字段保留兼容。Mac mini 保留公司账号、部门、NAS、模型配置、密钥及头像；云服务器只同步安装包镜像。

## 验证范围
