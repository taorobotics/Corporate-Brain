# v0.26.0 · Sonnet、Haiku 与智能生图技能

## 员工端更新

- LinoRoute 模型菜单补充经实际调用验证的 Claude Sonnet 和 Haiku 系列，继续使用供应商右侧展开菜单，与已有 Opus 型号一起选择。
- GPT Image 2.6 的 Sunburst、Flare 及两个 `-c` 型号作为图片生成技能接入。生图技能默认参与自动调度，保留当前文字对话模型，可与写作和设计技能组合；无需切换到图片模型对话。
- AI 根据需求选择生图技能：Sunburst 偏向精细成图，Flare 偏向快速预览和草稿；区分按次与按用量的型号。未明确偏好时优先 Sunburst-c，快速草稿优先 Flare-c，指定可用型号时遵循指定。每次选择一个图片接口，不自动把所有型号各调用一次。
- 普通聊天、比较模型、识图和文件分析不会因为安装了生图技能而触发出图。保留员工与部门授权、手动技能选择和仅可查看工作区限制。

## 管理员与服务器更新

本次新增模型配置与图片技能调度，无数据库结构变更。界面与业务服务随服务器包交付；更新前停止服务并一致性备份数据库、`secrets.key` 和部署配置，在新目录解压更新包、安装锁定依赖，沿用原数据目录与 HTTPS 设置启动。模型配置只追加实测通过的条目，原有连接 ID、密钥、授权与账号保留；公司密钥不包含在源码和安装包内。

连接已更新服务器的客户端重新打开即可加载新业务。Windows 安装包通过客户端“安装”入口后台升级；Mac 使用对应架构 DMG 替换。局域网专用包默认连接 Mac mini，公开发行包沿用公开发行配置，两者独立构建并分别校验。仅重新安装客户端不会自动替换服务器业务代码。

## 检查与边界

在 Mac mini 使用现有 LinoRoute 配置，分别对目录返回的 4 个 Sonnet、2 个 Haiku 进行最小文本调用，6 个全部返回 HTTP 200 及预期内容；对截图中的 4 个 GPT Image 2.6 型号分别实际生成 1024×1024 PNG，全部成功并校验图片格式和尺寸。目录由中转服务提供，调用成功不代表已验证原厂模型身份或未来可用性；不将服务商宣传的质量与价格作为保证。

新增回归覆盖四种图片技能的路由元数据、显式选择与缺省选择、单接口调用、兼容接口 base64 参数、普通聊天不出图、手动与部门权限。完整原生构建、安装及分发检查记录随 Release 发布。源码、安装包和公开检查记录不含公司数据库、密钥、员工聊天或内部技能。
