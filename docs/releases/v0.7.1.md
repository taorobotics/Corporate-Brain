# v0.7.1

## 员工端更新

- 客户端登录后自动检查公司服务器提供的 GitHub Release，并在左下角持续显示“有可用更新”、版本号和下载状态。
- 公开仓库模式默认启用；服务器不再要求先填写 GitHub Token 才能发现公开版本。私有仓库仍可通过 `BRAIN_GITHUB_TOKEN` 使用受控更新源。
- 更新弹窗会明确提示旧服务器包需要先升级，避免把“更新源未配置”误认为客户端没有自动检查。

## 管理与部署更新

- `server/updates.ts` 将公开仓库作为默认更新源，同时保留 `BRAIN_UPDATE_SOURCE=private|disabled|off|false` 的显式关闭开关。
- 更新源测试覆盖无配置环境下的公开 Release 发现、私有源、下载和重定向凭据隔离。
- 客户端页面、服务端更新接口和桌面更新逻辑随本版本一起交付；服务器升级后无需再填写公开仓库 Token，重启服务即可生效。

## 验证范围

- `npx tsx --test server/updates.test.ts desktop/updates.test.cjs`：10 项通过。
- `npm run build`：通过。
- 版本文件、发布包和校验文件由 Desktop release 工作流在 Windows x64、macOS arm64、macOS x64 与 Linux 服务器环境分别生成并复核。

## 部署说明

- 先备份服务器 `.data` 与部署环境，将 `Corporate-Brain-Server-0.7.1.zip` 解压到新的应用目录，再按现有数据库、密钥、HTTPS 和端口配置启动。
- 已安装的旧客户端会继续从公司服务器加载页面；升级服务器后，桌面客户端重新登录或获得焦点时会自动检查更新。客户端安装包仍通过左下角更新入口下载并校验。
- 本版本不包含 API Key、数据库、员工聊天、`.data`、`.cache`、`node_modules` 或 DSH 运行缓存。Windows 包未做可信代码签名，macOS 使用 ad-hoc 签名且未公证。
