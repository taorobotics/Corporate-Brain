# v0.10.0 · 实时思考过程与 Grok-ball

## 员工端更新

- 对话等待区域改为可展开、收起的思考过程：实时显示模型接口公开返回的思考正文，最终回答独立显示在下方。DSH 与直接连接的 OpenAI 兼容服务均支持逐段更新。
- 显示 DSH 实际工具调用的进行中、完成、失败状态；搜索工具返回来源时显示经过校验的链接及实际来源数量。不模拟搜索、不编造思考；模型未提供思考字段时明确提示。
- 用 Grok-ball 替换对话中的鲸鱼标识。适配暖色、深色、窄窗口和系统减少动态效果；历史记录里的球保持静止，窗口隐藏时暂停动画。
- 新增停止生成，停止或连接中断后保留已收到的正文和过程。切换会话不会串入其他会话的状态，过程随对话保存在本机，可导出、导入。
- 修复停止后再次发送可能出现的 DSH 会话冲突；不同员工、会话使用独立运行目录。重新建立运行时会补入客户端发送的历史上下文。

不是所有模型或服务商都公开思考内容。本功能显示 API 返回的可见思考与实际工具事件，不提取模型内部隐藏过程。搜索来源只在实际调用并返回来源时出现。

## 下载与更新

- Windows x64：`Corporate-Brain-Setup-0.10.0-x64.exe`。
- Apple 芯片 Mac：`Corporate-Brain-0.10.0-macOS-arm64.dmg`。
- Intel Mac：`Corporate-Brain-0.10.0-macOS-x64.dmg`。
- 公司服务器：`Corporate-Brain-Server-0.10.0.zip`。

客户端从公司服务器加载网页。管理员先备份数据库、加密密钥与配置，再部署服务器包；员工重启客户端加载新的思考过程界面。桌面安装包用于更新本机版本，不能代替服务端部署。旧客户端的 JSON 请求仍受支持。

公司私有仓库更新源尚未配置时，请使用交付的本地安装包手动更新。0.9.2 是被本次改版取代的未公开草稿，标签保留，不覆盖其资源。

## 验证

执行版本一致性、35 项后端与共享逻辑测试、TypeScript 检查、生产构建和真实 Electron 检查。后端使用隔离提供商运行真实 DSH，验证思考先于回答到达、取消、跨会话隔离与取消后重试；直接接口验证鉴权、UTF-8 分片、来源过滤、异常中断及旧 JSON 客户端兼容。

桌面使用明确标识的隔离流式响应，验证思考与回答分区、来源、折叠、停止、部分失败、无思考模型、历史恢复、减少动态效果及会话隔离。示例内容不代表真实搜索或模型推理。完整平台安装包、服务器包、SHA-256 和实际检查报告随 Release 提供。Windows 完整安装、升级、卸载仅在临时 CI 环境执行，不覆盖员工现有安装。
