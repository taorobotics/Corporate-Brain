# v0.27.2 · 对话文件回传与执行循环修复

## 员工端更新

- 修复 AI 已经在服务器生成文件，客户端却只显示超时、收不到成果的问题。普通 AI 对话生成的 GIF、图片、文档和代码可进入现有成果回传流程，无需选择另一种任务模式。
- 本轮生成的文件在专用交付目录中准备，校验后仅提交到当前员工、当前设备的接收队列；设置过本机保存位置时自动下载，尚未设置时可从回复选择保存位置。
- 成果列表支持 GIF 和图片预览。HTML、SVG 和代码继续按文字预览，不执行生成的代码；压缩包等文件通过成果文件夹打开。
- 限制单轮重复工具调用，已有可用成果时优先保留并交付；相同文字、思考快照和相同工具状态不再延长无进展等待。仍保留总时限、用户取消、账号及工作区权限。
- 修复开始对话、停止和重试时等待状态提前出现的问题，确保本机接收准备与当前响应流的状态一致。
- GIF 和动态表情包由对话执行器制作并交付实际文件，避免被当成静态生图或 MP4 视频任务；文件交付后释放对应执行器。
- 修复内容折叠或窗口调整后误暂停自动跟随的问题；手动上翻、键盘阅读和拖动滚动条仍会暂停跟随，回到底部后可继续。

## 管理员与服务器更新

本次同时更新服务器业务和客户端本地预览。服务器先停止服务并一致性备份数据库、`secrets.key` 与部署配置，再解压服务器包、安装锁定依赖并沿用原数据目录与 HTTPS 配置启动。没有新增员工、部门或模型配置，也不变更已有授权。

连接更新服务器的客户端重开后即可使用文件回传。GIF 内嵌预览需要本版桌面客户端；旧客户端可先用“打开成果文件夹”。Windows 从客户端“安装”入口后台升级并重启，Mac 用对应架构 DMG 替换。局域网包默认连接 Mac mini，公开发行包采用公开服务器配置，分别校验。

## 检查与边界

使用实际 SDK 和合成模型接口复现持续读取同一图片的执行循环，确认调用达到上限后停止，并保留已生成的真实文件。回归覆盖文件回传、账号与设备隔离、仅可查看工作区、路径穿越、链接文件、大小和数量限制、完整保存确认及本地 GIF 预览。实际模型与服务器部署结果在完整交付记录中补充。

本地 Windows 已通过 146 项 Node 测试、5 项 NAS 工作进程测试和生产构建；桌面 47 项、启动 9 项、个人资料 7 项、成果回传 5 项检查通过。新增桌面检查从普通对话提交合成 GIF 和说明文件，逐文件核对本机 SHA-256 与服务器清理，再验证 GIF 内嵌解码、回复及成果关联刷新后保留；这些检查使用隔离账号与合成服务，不计为真实模型调用。

只回传本轮专用交付目录内的普通文件，不扫描服务器其他目录，不打包运行时、隐藏缓存或内部技能。校验后的接收队列副本会保留至客户端确认完整保存；确认后清理服务器任务文件。生成文件不代表内容已通过人工质量审核。
