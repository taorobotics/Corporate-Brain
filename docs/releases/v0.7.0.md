# v0.7.0

## 本地文件夹与图片识别

- 桌面客户端可以只读扫描选定的工作区目录，读取常用文本、代码、配置和日志文件，并跳过 `.git`、`node_modules`、构建产物、缓存和公司运行数据目录。
- 用户在对话中直接输入 Windows 文件夹路径时，客户端会自动识别该路径并读取可识别内容；不再把 `D:\\...` 路径原样交给云端后让服务器尝试访问员工电脑。
- 目录内容以只读工作区摘要和图片附件发送给模型，带有文件清单、相对路径、大小和文本内容；扫描有文件数、大小和总量限制，超出时明确提示截断。
- 图片附件继续保留本地预览，同时进入 DSH 的图片输入；当 DSH 视觉预设无法处理图片时，自动回退到同一模型的 OpenAI 兼容视觉请求。
- 网络请求失败时显示可操作的公司服务连接错误，不再只显示浏览器的 `Failed to fetch`。

## 员工端更新

- 选择工作区目录后，直接提问“这个文件夹写了什么”即可让模型读取摘要。
- 也可以在问题中直接粘贴 Windows 目录路径；客户端只读扫描本机内容，不把本地绝对路径当作服务器目录。
- 上传图片后，模型会收到实际图片数据，而不只是看到附件名称和本地预览。
