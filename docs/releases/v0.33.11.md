# v0.33.11 · 修复调度断线阻断对话

## 员工端更新

- 修复“您好，你是谁？”等身份问答仍进入模型调度的问题。现在直接显示公司大脑助手身份与当前真实模型配置，不依赖上游调度服务，也不扫描项目或启动技能。
- 调度连接重置、连接超时、等待超时或上游临时不可用时，继续使用当前模型进行普通对话，并显示“调度暂不可用，继续普通对话”。当前附件及相关对话仍会提供给模型；回退不会自动启动文件、图片或视频制作，不会宣称工具已执行。
- 普通模型回复在收到响应前遇到连接故障时最多重试一次，沿用原取消与超时信号；已有部分输出时不重复请求。用户主动中止、模型凭据或权限错误仍明确处理，不伪装为执行成功。
- 调度回退记录脱敏的故障类别，便于区分连接、等待、临时服务和格式问题，不记录聊天正文、密钥或上游私密报错。

## 客户端与服务器更新

客户端和服务器包均为 0.33.11。客户端从公司服务器加载界面，本次必须更新服务器网页与业务服务才能生效；只安装客户端不会替换服务器代码。Mac mini 为主要部署目标，三平台安装包及更新源同步，云端备用安装包镜像继续保留。

更新前停止本项目服务并一致性备份原数据、密钥和配置。此修复不迁移员工记录，不改变账号、部门、NAS、技能与模型授权。上游服务整体故障时，普通模型请求本身仍可能失败；本版避免前置调度故障单独阻断可用的模型回复。
