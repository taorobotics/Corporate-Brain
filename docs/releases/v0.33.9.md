# v0.33.9 · 模型与服务按供应商折叠

## 员工端更新

- “设置 → 模型与服务”中的公司模型按供应商合并，默认只显示供应商名称和模型数量，点击后展开二级模型列表，再次点击收起。LinoRoute 保留推荐标识。
- 展开后仍可选用对话模型或使用图片技能；图片技能不会替换当前对话模型。兼容旧版 DeepSeek、LinoRoute 连接，保留每个模型的原有权限和选择标识。
- 个人连接和管理连接中的模型明细默认收起，管理模型、自定义配置和公司授权模型库入口继续保留。支持键盘展开以及深色、窄窗口布局。

## 客户端与服务器更新

客户端安装包与服务器包均为 0.33.9。界面由公司服务器加载，管理员必须部署本版服务器包才会显示两级模型列表；仅安装新版客户端不会替换服务器网页。Mac mini 为本公司主要部署目标，安装包与更新源一并同步，云端安装包镜像沿用现有分发流程。

部署前停止本项目服务并一致性备份数据、密钥和配置，保留原账号、部门、NAS 与模型配置。本版不迁移业务数据、不修改模型密钥和部门授权。

## 验收与许可

检查覆盖供应商合并、默认收起、键盘和鼠标展开收起、模型选择持久化并用于对话、图片技能入口，以及深色窄窗口。正式 Release 随附 Windows x64、Mac arm64/x64 安装包、公司服务器包、SHA-256 及三平台真实检查记录；以随包记录为实际通过范围。

原创代码采用 MIT，第三方许可与隐私说明随包保留。Windows 尚未可信签名；Mac 为 ad-hoc 签名、未公证。

本地生产构建、197 项 Node 测试、8 项 NAS 协议测试、63 项完整桌面交互检查及 7 项账号资料检查通过。模型列表以 30 个模型实际验收，覆盖初始折叠、键盘展开、选用后对话生效、图片技能、真实深色主题及 700px 窄窗口。
