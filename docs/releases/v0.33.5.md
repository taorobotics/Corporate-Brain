# v0.33.5 · 客户端页面缩放快捷键

## 员工端更新

- Ctrl＋“+”放大整个客户端页面，Ctrl＋“-”缩小，Ctrl＋0 恢复 100%。支持 Ctrl＋“=”和小键盘加减键。
- Mac 同时支持 Command 对应快捷键，以及 Control 组合键。
- 登录页和对话页均可使用，输入框有焦点时也有效；单次按键只执行一次缩放，保留输入内容。

## 客户端与服务器更新

**这次需要安装 0.33.5 客户端，单独刷新服务器页面不会增加原生快捷键处理。** Windows 可从左下角更新入口下载安装，沿用原目录自动重启；Mac 使用对应架构的 DMG 替换应用。原公司地址、本地对话、项目和个人偏好保留。

服务器更新包与公司安装包镜像同步为 0.33.5，部署前一致性备份。账号、部门、NAS、模型配置及密钥不包含在公开资源中。

## 验证范围与许可

原生桌面验收验证登录页、对话输入框、主键盘与小键盘快捷键、真实页面缩放、恢复默认、避免重复触发及 AltGr 组合键保留。正式 Release 包含三平台安装包、服务器包、SHA-256 与实际验收记录。

原创代码采用 MIT，第三方许可和隐私说明随包保留。Windows 未做可信签名；Mac 仅 ad-hoc 签名、未公证。
