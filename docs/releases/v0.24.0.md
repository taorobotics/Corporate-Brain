# v0.24.0 · 员工个人模型与 LinoRoute 模型库

## 员工端更新

- “模型与服务”新增“我的模型连接 → 自定义配置”，员工可添加自己的官方 API 或兼容中转服务，搜索并多选模型。
- LinoRoute 位于服务商首位并标记推荐，同时保留 DeepSeek、Kimi、千问、腾讯混元、智谱、MiniMax、OpenAI、Gemini、Claude 预设。
- 已获公司 LinoRoute 服务授权的员工，可从“公司授权模型库 → 浏览 / 选择模型”读取上游完整目录，选择管理员尚未加入默认列表的模型，无需填写公司密钥。每次最多保存 200 个模型，实际调用权限与费用以服务商套餐为准。
- 个人配置仅自己可用，没有部门授权或分享选项，不影响同事的选择。个人图片模型自动成为仅本人可用的图片技能，可在聊天中按需调用。
- 公司模型库派生连接实时继承公司密钥、地址与部门权限；公司撤权或停用源服务后同步失效。移除个人连接保留本机历史。

## 管理员与服务器更新

公司服务仍由公司管理员统一管理。员工个人连接与公司配置分离，接口不返回密钥；个人密钥在服务器加密保存，更换地址需重新填写。个人 API 使用公网 HTTPS，实际连接时校验 DNS 并拒绝本机、内网、保留地址及重定向。DSH 工具对话保留，通过受限连接访问个人上游。

本次界面和业务代码由服务器包交付。更新前先停止并一致性备份数据库、`secrets.key` 和配置，在新目录解压服务器包并安装锁定依赖，沿用原数据目录及 HTTPS 配置启动。新增个人服务归属字段，旧公司连接、账号、部门与密钥保留。

客户端安装包与服务器分别更新。Windows 可在客户端检查更新并点击“安装”，Mac 使用对应架构 DMG 替换；仅更新安装包不会替换公司服务器上的业务界面。

## 检查与边界

新增测试覆盖个人密钥加密、本人/他人/管理员调用隔离、伪造归属拒绝、LinoRoute 完整目录个人选用、公司地址密钥轮换及撤权、个人聊天与图片技能、DNS 连接校验和 DSH 代理。原生界面验收覆盖员工配置弹窗无部门授权、浅深色与窄窗口、搜索多选、实际对话调用、重载及删除。完整跨平台构建和检查记录随 Release 分发。

隔离测试不消耗真实模型额度，不代表所有预设服务商或目录模型都已实际付费调用。源码及安装包不包含公司密钥、数据库、员工聊天或内部技能。原创代码使用 MIT，第三方保留原许可；隐私说明随客户端和服务器分发。Windows 未获可信代码签名，Mac 使用 ad-hoc 签名且未做 Apple 公证。下载后可通过 SHA256SUMS.txt 校验。
