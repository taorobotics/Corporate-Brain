# v0.19.1 Windows 后台更新

## 员工端更新

- Windows 更新按钮改为“安装”。保存本机记录、确认登录并再次校验安装包后，在后台沿用已登记的原安装目录更新，完成后自动打开公司大脑。
- 安装准备时显示状态并阻止重复点击；安装程序未能启动、准备失败或超时时，保持客户端打开并显示可重试的提示。
- 不重复询问安装位置，保留原桌面快捷方式选择；首次安装默认不创建桌面快捷方式，程序默认安装在应用目录。
- 账号、本地对话、草稿和公司连接保留。更新程序等待客户端自行退出，不强制终止工作。
- 兼容旧版 Windows 客户端直接打开已校验的更新缓存文件。旧版自身的原生确认框仍可能出现一次；进入新版后不再有该重复确认。普通手动下载、首次安装仍使用安装向导。
- Mac 继续打开 DMG 并拖入 Applications 替换；本次后台安装改动适用于 Windows 个人安装。所有用户安装仍需管理员权限。

## 安装与服务器更新

客户端需安装 v0.19.1 才能使用新的原生安装交接。公司服务器也需更新本版本服务器包，才能显示“安装”、准备状态及对应说明。服务器更新先一致性备份，再继续使用原数据库、secrets.key、模型配置与 HTTPS 设置。

旧客户端已下载的 v0.19.0 安装包不会被改写；重新检查并下载 v0.19.1 后才会使用新版安装流程。

## 验证与发布状态

- Windows：81 项 Node 测试、5 项 Python NAS 测试、类型检查和网页生产构建通过。
- 新增安装交接 7 项回归测试通过，新增模块行覆盖率 100%、分支覆盖率 88%。测试不执行真实安装包。
- 原生 NSIS 隔离交接的 5 项检查通过：手动安装区分、非法令牌拒绝、准备超时安全取消、新版双向交接与旧版缓存启动，后两项均检查等待旧进程和重新出现真实窗口。仅使用无数据的测试程序，不等同于完整安装升级验收。
- 原生安装器已增加无继续信号安全取消、等待旧进程、无向导更新、目录与记录保留、快捷方式选择和自动重启的隔离 Windows 验收；必须在隔离环境实际通过才视为生命周期验收完成。
- 后续本机与 Mac mini 构建、部署及检查结果记录于本版本交付报告。尚未完成的检查不可视为通过，不将草稿视为已公开正式 Release。
- Windows 当前未获可信签名；Mac 仅 ad-hoc 签名，未经 Apple 公证。
