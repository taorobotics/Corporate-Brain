# v0.8.2

## 员工端更新

- Windows 安装向导的主按钮、返回、取消、浏览等按钮增加明显的悬停和按压反馈，按下时压低、收紧并改变底色，松开恢复；保留键盘焦点和原生操作语义。
- 点击「立即打开」立即显示「正在打开」，阻止重复启动。向导确认客户端窗口出现后才关闭；未能启动或长时间没有窗口时保留「重试打开」和「完成」入口。
- 普通用户安装后直接启动客户端程序，减少快捷方式和资源管理器的转发；管理员启动的安装器仍通过普通用户上下文打开客户端。
- 客户端先显示本地启动画面，再连接公司页面。连接失败或超时有明确提示及重试按钮，不再留下没有解释的空白窗口。
- 已打包客户端重复启动时恢复已有窗口，避免第二个进程争用本机记录目录。

## 更新方式

- 本次修复位于 Windows 安装向导和桌面客户端，需运行新版安装包。仅刷新公司服务器页面不能更新旧安装程序的按钮和启动逻辑。
- macOS 客户端包含本地启动提示和重复启动处理；Windows 专有安装向导仅随 Windows 安装包交付。
- 公司服务器包随本版本提供，业务接口和皮肤保持原有行为；当前服务器不需要为此次安装交互修复停机更新。

## 检查与分发

- 本地检查：按钮按下前后真实窗口像素对比；真实 Electron 慢网启动、连接成功、超时恢复和重试；主客户端原有交互回归；后端与共享逻辑测试、生产构建。
- Windows 发布检查增加启动失败后的重试、重复启动复用已有进程，继续验证旧版覆盖升级、取消、卸载和本地记录保留。完整结果随 Release 检查文件分发。
- Windows 未做可信代码签名；macOS 为 ad-hoc 签名，未做 Apple 公证。
- 不含密钥、公司数据库、员工记录或开发缓存。
