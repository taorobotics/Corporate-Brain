# 公司大脑 0.17.2

## 员工端更新

- 修复 Logo 虽为透明图片、界面却额外添加白色底托的问题。员工侧栏、后台、登录、启动动画和对话欢迎页直接显示透明脑形 Logo。
- Windows 安装、卸载、桌面与窗口图标、macOS 应用图标、浏览器及书签图标均移除白色底托，保留脑纹与网络线之间的透明区域。
- 深浅色界面使用同一选定图形，不改变 Logo 的颜色与设计；构建时检查内部透明区域，避免白底再次进入安装包。

## 客户端与服务器更新

平台内的 Logo 容器随 Mac mini 网页更新；原生启动页、系统图标和安装向导需安装本版客户端。更新前一致性备份，保留原账号、部门、NAS、技能、模型配置及密钥。
