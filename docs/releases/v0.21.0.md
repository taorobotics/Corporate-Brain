# v0.21.0 部门账号与员工自助管理

## 员工端更新

- 个人设置增加“修改登录账号”，验证当前密码后可自定义唯一登录名，保留员工身份、部门权限、头像及本机对话；其他设备需重新登录。
- 员工可修改显示名称、头像和密码。首次使用批量随机账号须改密；改密后所有设备重新登录。
- 改密界面明确说明这是公司管理的内部账号，公司管理员验证身份后可查看当前密码，查看操作留记录。

## 管理后台

- 公司管理员可按部门随机开通账号，每部门默认 20 个，随机登录名、显示名称和独立密码，权限为所属部门普通员工。批量初始密码 30 天内有效，同一批次重试不重复创建。
- 员工表格增加当前密码查看，须逐次验证公司管理员密码，30 秒后自动隐藏；员工修改密码后同步更新可查看的记录。部门管理员、审核员和员工不能查看，公司管理员密码不提供查看副本。
- 登录校验保留不可逆密码摘要；可查看的密码使用部署密钥加密保存。普通清单导出、日志及审计不含密码。旧密码摘要不可还原，旧账号下次改密或重置后才可查看。

## 客户端与服务器更新

本次功能包含服务器网页和账号服务，管理员应先一致性备份数据库与 secrets.key，再部署新的服务器包。保留原账号、部门、NAS、技能、模型密钥及 HTTPS 配置。连接更新后 Mac mini 的客户端重新打开即可加载新版；安装包更新在员工设备完成，Windows 沿用原目录后台安装并重启，Mac 使用对应架构 DMG。

局域网安装包默认连接 Mac mini；GitHub 正式安装包使用公司发布地址，已有客户端保留选择的服务器。云端只同步安装包镜像，本次不修改旧云业务服务。随机账号和管理员凭据仅写入内部公司数据库与专用私密交付文件，不进入开源仓库或安装包。

## 验证范围

检查随机批量开通、重复请求、越权拒绝、密码加密保存及改密同步、管理员查看验证与审计、登录名冲突、原账号身份保留及其他设备登录撤销。另运行既有单元测试、类型检查、生产构建、桌面交互与三平台安装检查。实际部署、安装包与分发校验记录在交付时补充。
