# v0.21.0 部门账号与员工自助管理

## 员工端更新

- 个人设置增加“修改登录账号”，验证当前密码后可自定义唯一登录名，保留员工身份、部门权限、头像及本机对话；其他设备需重新登录。
- 员工可修改显示名称、头像和密码。首次使用批量随机账号须改密；改密后所有设备重新登录。
- 改密界面明确说明这是公司管理的内部账号，公司管理员验证身份后可查看当前密码，查看操作留记录。

## 管理后台

- 公司管理员可按部门随机开通账号，每部门默认 20 个，随机登录名、显示名称和独立密码，权限为所属部门普通员工。批量初始密码 30 天内有效，同一批次重试不重复创建。
- 员工表格增加当前密码查看，须逐次验证公司管理员密码，30 秒后自动隐藏；员工修改密码后同步更新可查看的记录。部门管理员、审核员和员工不能查看，公司管理员密码不提供查看副本。
- 登录校验保留不可逆密码摘要；可查看的密码使用部署密钥加密保存。普通清单导出、日志及审计不含密码。旧密码摘要不可还原，旧账号下次改密或重置后才可查看。

## 客户端与服务器更新

本次功能包含服务器网页和账号服务，管理员应先一致性备份数据库与 secrets.key，再部署新的服务器包。保留原账号、部门、NAS、技能、模型密钥及 HTTPS 配置。连接更新后 Mac mini 的客户端重新打开即可加载新版；安装包更新在员工设备完成，Windows 沿用原目录后台安装并重启，Mac 使用对应架构 DMG。

局域网安装包默认连接 Mac mini；GitHub 正式安装包使用公司发布地址，已有客户端保留选择的服务器。云端只同步安装包镜像，本次不修改旧云业务服务。随机账号和管理员凭据仅写入内部公司数据库与专用私密交付文件，不进入开源仓库或安装包。

## 验证范围

检查随机批量开通、重复请求、越权拒绝、密码加密保存及改密同步、管理员查看验证与审计、登录名冲突、原账号身份保留及其他设备登录撤销。既有单元测试、类型检查、生产构建、桌面交互与三平台安装检查均已通过，实际部署与安装包验证见下方记录。

## 许可与隐私

原创代码 MIT，保留第三方许可。Windows 未取得可信代码签名；Mac 使用 ad-hoc 签名，未做 Apple 公证。隐私说明已更新，内部账号凭据与密钥须由公司妥善保管。

## 实际部署记录

- Windows 和 Mac mini 各通过 101 项 Node 测试、5 项 NAS 工作进程测试、类型检查及生产构建；Windows 桌面 41 项、Mac 桌面 40 项，各自启动 9 项。
- 两个平台的个人资料与账号界面均通过 6 项检查，涵盖随机批量开通、管理员密码验证与查看、员工首次改密、自助修改登录名、冲突提示、原身份和部门保留，以及后台显示修改后的登录名与当前密码。测试仅使用合成账号，不调用生产模型。
- Mac mini 一致性备份后升级至 0.21.0，原账号、13 个部门、14 个 NAS 来源、3 个技能、模型配置和加密密钥核对保留。为 11 个业务部门各新增 20 个普通员工账号，另新增一个独立公司管理员，原 3 个账号保留，共 224 个账号。所有新员工密码密文与登录摘要匹配。
- 从实际 Windows 电脑通过严格验证证书的 HTTPS 登录，核对管理员权限、220 个员工的部门分配、当前密码查看、员工首次登录及改密限制，员工不能访问账号管理。账号凭据只在内部数据库和私密交付文件中，不进入公开记录。
- 局域网 Windows x64 和 Mac arm64 更新通道已启用 0.21.0，通过临时账号完整下载安装包并核 SHA-256；随后删除该验收账号并核对现有账号未变。Mac 另完成真实成片预览与 3 秒、72 帧、1280×720 的带音频渲染。
- 本地安装包界面检查首次在像素取样边界处失败，同一工具顺序复跑通过。正式 Windows 安装验收在旧客户端关闭时超时，控制验收工具改为与独立安装工作流一致的离线公司入口，并在关闭前刷新进程窗口句柄；包内默认服务器地址仍独立核验，全部安装、升级、自动重启与数据保留断言保留，产品标签和源码不变。
- 正式 Windows 原生安装生命周期通过 17 项检查，另有 5 项原生更新交接检查；覆盖旧版升级、后台自动安装及重启、取消和失败重试、卸载与个人记录保留。Mac arm64、x64 安装包均通过挂载与首次启动检查，GitHub Release 的 13 个资源和四份安装／服务器包摘要已核对。
- 补充的独立安装回归曾在进程刚启动时将 ntdll.dll 误读为客户端路径；验收脚本改为读取 Windows 提供的进程可执行文件路径，仍严格核验目标程序。该修正仅用于后续验收，不修改已发布产品标签或安装包。
- 修正后的独立安装回归已通过。公网镜像传输因速度较慢达到 30 分钟任务上限而终止，旧更新源继续可用；用户追加的账号分配备注随 v0.21.1 交付，该版本延长分发时限并接续完成公司镜像更新。v0.21.0 的局域网通道已验证，不将未完成的公网分发标为通过。
- 后续 v0.21.1 已完成正式发布和公网镜像校验，原账号全部保留，并增加账号分配备注。当前完整交付记录见 artifacts/macmini-v0.21.1-delivery.json；本版标签和安装包保持不变。
