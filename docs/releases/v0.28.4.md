# v0.28.4 · 输入框中止与补充要求

## 员工端更新

- 回复中不再显示“停止任务”或“停止生成”，运行中的对话统一在输入框右下方显示方形中止按钮；正常完成后恢复发送箭头。
- 对话、图片、代码和视频使用同一入口。中止保留已收到的回答和本机文件，取消当前对话正在执行的请求或后台任务；已完成、等待保存的成果继续保留。
- 执行中可以输入补充要求，点击发送或按 Enter：先确认中止当前执行，再结合已保留内容继续同一对话。中止失败会保留草稿，不自动启动下一次执行；切换对话也不会误发补充要求。
- 任务刚创建、上传或识别需求时也能中止。中止和发送适配深浅色、键盘操作和窄窗口。

## 客户端与服务器更新

本次界面与取消逻辑均随服务器包交付。Mac mini 备份更新后，已有客户端重新打开即可使用；客户端安装包同步更新至 0.28.4，Windows 可通过左下角更新入口校验后安装并重启，Mac 按架构使用 DMG 替换。

Mac mini 保留原数据库、账号、部门、NAS、技能、模型密钥和 HTTPS 配置。云服务器只同步安装包镜像，原业务服务保持运行。

## 验证与发行说明

验证使用隔离资料和合成模型，覆盖真实请求中断、部分回答保留、同一对话继续、补充要求只发送一次、跨对话隔离、中止失败保留草稿、任务创建与上传边界、完成成果保护、图片请求取消，以及实际原生桌面浅色和深色窄窗口。实际平台、安装和分发结果以本版本检查报告为准。
