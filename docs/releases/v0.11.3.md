# v0.11.3 · 减少启动时的字体下载等待

## 员工端更新

- Windows 优先使用电脑已有的中文字体，避免每次冷启动为了显示中文而先下载约 7.8 MB 的完整字体文件。
- 保留启动动画、跳过按钮和皮肤字体；没有可用系统中文字体的设备继续使用随项目提供的开源字体。
- 本次优化减少慢网、代理或 VPN 环境中的启动流量，不改变用户代理或 VPN 设置，也不保证所有网络环境的固定启动时长。

## 下载与更新

Windows x64：`Corporate-Brain-Setup-0.11.3-x64.exe`；Mac：`Corporate-Brain-0.11.3-macOS-arm64.dmg` 和 `Corporate-Brain-0.11.3-macOS-x64.dmg`；公司服务器：`Corporate-Brain-Server-0.11.3.zip`。

公司管理员备份数据和配置后部署服务器包。连接本公司服务的员工重新打开客户端即可获得网页字体优化；安装包同步包含本地启动页的字体优先级更新，可通过左下角更新入口安装。

## 诊断与验证范围

本机已复现：代理下网页加载完成后，大字体下载期间初始化请求等待 20 秒后超时；保持代理开启、仅在隔离测试中屏蔽该字体后，初始化和登录检查恢复响应。服务器本机接口响应约 0.05 秒，当前机器通过真实地址和物理网卡访问同一接口约 0.05–0.07 秒，通过当前代理约 1.7–2.5 秒。这些数字是本次网络样本，不是普遍性能承诺。

发布流程运行类型检查、生产构建、后端测试、真实 Electron 启动和界面检查，以及 Windows 安装升级与两种 Mac 包检查。真实报告和 SHA-256 随 Release 提供；云端部署后的启动验证单独记录。不读取员工聊天、不更改系统网络设置。
