# v0.34.13 · 项目和最近对话可独立收起

## 员工端更新

- 左侧“项目”和“最近”标题增加展开、收起按钮，两个栏目可分别控制，支持鼠标及键盘操作。
- 按当前员工账号在本机保存收起状态，重新打开或切换页面后恢复；不删除项目和对话。
- 收起最近对话后，项目列表可使用腾出的空间。搜索保持可用，新建项目会展开项目栏目。
- 保留 Noto Sans SC 本地分片字体及原有项目内单独收起对话的功能。

## 客户端与服务器更新

客户端与服务器版本均为 0.34.13。Mac mini 更新服务器包后，员工重新打开界面即可使用栏目折叠；本机偏好随原有账号记录保存。Windows 可沿用原目录后台更新，Mac 使用对应架构 DMG，公司更新源同步提供新版安装包。部署前一致性备份现有数据、密钥和配置。

## 验证与许可

检查栏目分别收起和展开、键盘激活、空间分配、本机重启后恢复及旧记录默认展开；验证搜索、项目切换和浅深色窄窗口仍可使用。正式发布须通过 Windows x64、Mac arm64、Mac x64、服务器包及更新分发检查。
