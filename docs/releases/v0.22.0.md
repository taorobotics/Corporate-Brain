# v0.22.0 服务商预设与多模型配置

## 员工端更新

- 同一个服务可开放多个模型，员工可在对话模型菜单中按权限选择，无需自己填写服务密钥。
- 保留原有对话和模型连接 ID，未授权、未选择或停用的模型无法调用。

## 管理后台

- “模型与服务”新增“自定义配置”按钮和弹窗。LinoRoute 放在第一位并标注“推荐”；预设 DeepSeek、Kimi、千问、腾讯混元、智谱、MiniMax、OpenAI / GPT、Gemini、Claude 官方兼容地址，并支持完全自定义。
- 一个地址和密钥配置一次，通过“获取 / 刷新模型”获取列表、搜索及批量勾选；不提供列表的服务支持手动添加模型标识。获取列表不发起内容生成。
- 已有 LinoRoute 连接自动保留原模型与部门范围，进入“管理模型”即可用原密钥刷新列表。更换地址需要重新填写密钥，防止旧密钥被发送到新地址。
- 多模型共用一份加密密钥。修改地址、密钥和部门范围同步生效，移除模型只停用对应连接，再选中时恢复原 ID。列表获取失败不改变已保存配置。

## 客户端与服务器更新

本次界面和业务由服务器提供，先一致性备份数据库、密钥和配置后部署本版服务器包。自动增加服务商表和连接引用，保留账号、部门、NAS、技能及现有模型配置。连接该服务器的客户端重新打开即可加载界面。

Windows 安装包支持现有后台安装并自动重启；Mac 按架构使用 DMG。局域网安装包默认连接 Mac mini，GitHub 正式包使用公司发布地址，已有客户端继续保留选择的公司服务器。云端更新分发与业务服务分别处理。

## 检查记录

实际测试及部署结果以本版的原生平台 JSON、服务器包检查记录和最终交付报告为准。使用隔离模拟服务验证发现多个模型、实际按选择路由、共用密钥、密钥更换、连接 ID 保留、部门越权拒绝及失败不改变配置。各家官方预设不代表已持有或调用其付费模型。

发版前 Windows 已通过 112 项 Node 测试、5 项 NAS 工作进程测试、类型检查和生产构建，原生桌面检查与启动检查通过。新增原生检查覆盖 11 个服务商入口、官方地址预填、多个模型勾选保存、空密钥复用、刷新保留选择、搜索及深色窄屏。初次与构建同时执行的测试曾出现 DSH 启动超时和本机调度请求失败；分项复核及随后完整测试均通过。原生测试曾因无请求体的停用操作被服务拒绝，已统一发送 JSON 并重新完整通过。
