# v0.28.3 · 提问复制与发送时间

## 员工端更新

- 每条员工提问下方新增复制按钮，复制原始提问，保留换行与 Markdown；已有原文记录时，不附带自动追加的附件标签。
- 提问气泡下方显示发送时的本机时间，例如“17:00”；每条提问前增加居中的“今天 17:00”“昨天 15:31”或具体日期标记，完整日期和秒数可悬停查看。
- 时间沿用消息原有的发送记录，按员工电脑当前时区以 24 小时制显示，重新打开不变成当前时间。没有有效时间记录的历史提问保留复制功能，不补造发送时间。
- 按钮和时间位于气泡外侧，沿用客户端字体与皮肤，适配深色和窄窗口。
- 本版客户端在剪贴板短暂被占用时有限重试，确认原文已写入后才提示复制成功；持续失败会明确提示，避免“显示成功但没有复制”的情况。

## 客户端与服务器更新

本次界面随服务器包交付。Mac mini 备份部署后，已有客户端重新打开可见；复制确认与重试需要本版客户端。桌面安装包同步递增为 0.28.3，Windows 可在左下角检查更新、校验后安装并自动重启，Mac 使用对应架构 DMG 替换。

服务器沿用原有数据库、密钥、账号、部门、NAS、模型和 HTTPS 配置。Mac mini 承载业务，云服务器只同步安装包镜像。

## 验证与发行说明

验证覆盖本机时间、今天与昨天、跨月跨年、午夜 00 点、无效历史时间，以及原生剪贴板复制、气泡外布局、真实深色窄窗口和重新打开后的记录保持。界面测试使用隔离资料；实际构建、安装与更新分发以本版本检查报告为准。
