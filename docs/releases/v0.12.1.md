# v0.12.1 · 紧凑的处理过程面板

## 员工端更新

- 思考与工具处理过程改成限高的滚动区域：常规窗口最高 220px，窄窗口最高 160px，并按窗口高度进一步适配。
- Grok-ball、状态和耗时保留在上方，“处理过程”可以独立展开或收起；左侧细线、浅色文字与客户端字体和皮肤保持一致。
- 思考内容在框内自动跟随。手动上翻或用键盘回看时暂停，可点“跟随最新内容”恢复；不会连带滚动外层对话。
- 收到正式回答时自动收起一次。之后主动展开不会因后续回答片段再次被收起；历史过程仍可回看。
- 只呈现服务端实际返回的过程与来源，不新增模拟思考或延迟回答的动画队列。

## 更新方式

Mac mini 公司服务器需更新网页与服务包，原有客户端重新打开即可加载新界面。Windows 与 Apple 芯片 Mac 的 0.12.1 安装包同步到 Mac mini 私有更新通道，员工可在左下角检查、下载并校验后打开安装包。账号、部门、模型配置与本地聊天不迁移或清空。

GitHub 按此前要求继续暂停；Intel Mac 未生成新包，保持原完整通道。本次为私有局域网交付，不代表完成公开三平台 Release。

## 验证范围

沿用真实 Electron 流式测试，检查限高、内部滚动跟随、鼠标/键盘暂停与恢复、外层滚动隔离、首次回答自动收起、手动重开、深浅主题与窄窗口。继续运行原对话滚动、回答操作和反馈流程回归。实际平台与交付检查记录随包提供。

Windows 仍无可信代码签名；Mac 为 ad-hoc 签名、未公证。没有在员工办公设备执行自动覆盖安装/卸载；未验证 Intel Mac。
