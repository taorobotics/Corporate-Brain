# v0.6.0

## 对话内容展示

- 对话回复支持常用 Markdown：标题、段落、强调、链接、引用、列表、代码块和分隔线。
- Markdown 表格会渲染为可滚动、可读的表格，避免把 `|` 和 `---` 当作普通文本显示。
- 对包含足够一致数值的数据表，自动增加轻量数据概览条形图；混合指标只选择可比较的数值组，避免制造误导性图表。
- 链接仅允许安全的 HTTP、HTTPS 和 mailto 协议，消息内容不会直接执行模型返回的 HTML。

## 员工端更新

- 员工无需改变使用方式，模型返回表格或适合比较的数据时会自动获得更清晰的展示。
- 表格过宽时可横向滚动，窄屏客户端也保留列标题和数值可读性。

## 验证

- `npm run build`：通过。
- 串行服务与桌面更新测试：通过。
- Electron 实窗口验收：通过。

## 部署

- 网页渲染代码随公司服务器更新包交付；桌面客户端刷新或重新打开即可加载。
- Windows x64 安装包和服务器更新包使用同一版本号；包内不包含 API Key、数据库、员工聊天或运行缓存。
