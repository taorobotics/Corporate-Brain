# v0.34.0 · 开源社区插件

## 员工端更新

- 设置新增「开源社区插件」，采用公司大脑自己的标志、字体和主题，提供已适配、全部社区、我的插件三个列表，支持搜索、分类、分页、来源详情和刷新。
- 全部社区读取公开社区目录，保留原作者、开源项目链接和许可提示；收录不代表 DeepSeek 或公司官方认证。尚未适配的条目可以了解来源，当前不能安装执行，不将第三方界面直接嵌入公司客户端。
- 首批提供「数学计算器」与「跑步配速计算」两个公司适配版。员工可以安装、启用、停用或卸载，设置随当前公司账号保存。AI 根据问题和上下文选择已安装且启用的工具，普通问候不启动插件工作流。
- 计算器支持四则、幂、开方及常用函数，采用浮点计算，不作为财务精确结算工具。跑步配速支持距离、分钟和秒数，校验零值、无穷值及非法时间。
- 其他皮肤、启动页、桌宠及原生桌面插件需要各自适配，不因列在社区目录中就承诺可以运行。技能中心的技能与社区可执行插件仍保留各自的安装流程。

## 客户端与服务器更新

客户端和服务器包均为 0.34.0。客户端从公司服务器加载界面；管理员需部署服务器网页及业务包，单独更新桌面安装包不会替换服务器代码。Mac mini 为主要部署目标，云端备用更新镜像继续保留；三平台安装包和校验文件随 Release 分发。

数据库新增仅保存账号与插件启用状态的 `community_plugins` 表。部署前需停止本项目服务并一致性备份原数据库、密钥和配置。不会替换账号、部门、NAS、模型设置、技能或员工本地对话。

社区目录只从两个固定公开地址读取，无公司模型凭据，限制下载大小和读取时间，缓存元数据并合并并发请求；刷新失败保留上次成功结果时明确标注时间和提示。已适配列表不依赖社区目录在线。目录安装命令、脚本、第三方图片和未适配代码不会执行或装入共享服务。

## 验证范围与许可

验证覆盖社区目录校验、固定地址读取、缓存和并发、未适配安装拒绝、账号隔离、登录与请求来源校验、安装启停卸载、智能调度授权，以及真实 DSH 工具调用。对同一个对话改变插件选择后会重建运行环境，验证旧插件不会继续出现在下一次请求中。模型测试使用本地合成服务，不调用生产模型。

桌面交互检查覆盖公司标志与命名、三个列表、搜索、来源详情、按账号安装停用卸载，以及深色窄窗口。正式三平台构建、原生安装及更新分发结果以 Release 附带的真实检查记录为准。

本机 206 项 Node 测试、8 项 NAS 协议测试及 68 项完整桌面交互检查通过；针对最终社区适配器的 5 项检查与生产构建另行复核。员工界面截图使用独立测试账号及合成社区目录，不读取真实员工数据。

数学解析器来自 `omdsh-dev/dsh-tool-calculator`，固定源码提交 `b2007a13f06bcf75bf07b9d277ee8d434a316490`，保留 MIT 原文；公司提供适用于当前内核的新工具封装。配速适配参考 `uckkk/dsh-pace-calc@0.1.1`，保留 MIT 原文，补充时间和距离校验。第三方版权与许可证随包交付。

原创代码采用 MIT。Windows 尚未取得可信代码签名；Mac 使用 ad-hoc 签名、未公证。
