# v0.34.5 · 直接登录与自适应排版

此版本未公开：Windows 桌面验收在刷新后的管理页存在读取旧页面的竞争，已定位为验收导航没有等待新文档及模型记录加载。后续 v0.34.6 修正验收后重新构建交付，不替换此版本标签或安装包。


## 员工端更新

- 未登录打开客户端时直接进入星球登录页，移除正常启动时的黑底标志与旧版暖色动画过场，也不再等待固定的开场和进入动画。
- 登录页根据窗口高度调整卡片、星球区域及上下留白。常用桌面尺寸、125% 与 150% 缩放及窄窗口下完整显示账号、密码、登录按钮和底部入口，不再出现右侧页面滚动条。
- 极小窗口或较大缩放下仍可通过滚轮、触控板和键盘访问完整表单，不裁切登录内容。登录失败提示、初始化表单、窗口按钮、深浅色和隐私与许可入口保留。
- 保留设置中的手动启动动画预览。网络连接或账号读取未完成时显示实际状态，连接失败仍可重试，证书验证照常执行。

## 客户端与服务器更新

客户端与服务器版本均为 0.34.5。本次必须同时更新桌面客户端和公司服务器：登录排版由服务器提供，旧版安装客户端的本地启动层须安装新版后才能完全替换。Windows 可从客户端更新入口后台升级并自动重启；Mac 使用对应芯片的 DMG 更新。

Mac mini 为主要部署目标。服务器更新包包含编译网页与锁定依赖；在新的版本目录准备依赖，部署前一致性备份数据库、加密密钥及本项目配置，继续指向原有数据，不覆盖公司账号、部门、NAS、技能、模型配置与员工本机对话。云端备用安装包镜像继续分发。

## 检查与许可

新增真实 Electron 冷启动检查，记录登录首次挂载并检测旧场景和表单禁用状态；校验多个窗口尺寸及缩放下的实际内容高度与控件位置，另行验证极端缩放时键盘仍可到达底部。原生连接检查覆盖未就绪页面保护、缓慢资源、超时、自动与手动重试、预览、窗口关闭和证书失败，不调用生产模型。

本机 206 项程序测试、8 项 NAS 测试、完整桌面交互、个人资料、任务流程、原生连接与实际 WebGL 登录页检查通过。三平台原生安装包检查结果以 Release 附件为准，最终分发和 Mac mini 验收记录将在交付完成后补充。
