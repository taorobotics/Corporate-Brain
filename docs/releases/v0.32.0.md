# v0.32.0 · 对话联动技能中心与公司知识

## 员工端更新

- 在对话中询问“现在有哪些技能 / skills”“你能做什么”时，查询当前账号获准的真实技能中心目录，区分已安装、可安装及依赖尚未接通的技能；仅询问目录不会执行技能流程。
- 在对话中询问“NAS 有哪些文件夹”时，读取公司知识中当前部门获准的 NAS 目录，不再用本地项目文件夹代替。支持指定资料源、进入子目录、按当前目录内的文件名称查找。
- “打开刚才那个目录”“在里面找说明”等追问会结合前文及上一轮资料源与相对路径判断；相关记录保存在员工本机，重新打开对话后仍可继续。
- 对话处理过程显示真实的技能中心、公司知识查询进度。目录读取失败会据实说明，不当作空目录，也不回退到员工本地项目。

本版接通技能目录和 NAS 目录、名称查询，不递归扫描整个 NAS，不自动读取文件正文。目录名称不能代替文件内容，AI 不应据此编造文档内容。技能执行仍按员工已安装和已授权范围选择。

## 权限与数据

对话和公司知识页面使用同一 NAS 服务、部门授权、路径校验、频率限制及错误处理。公司管理员身份不自动取得其他部门文档权限；查询中撤销资料源或账号权限会中止返回。NAS 凭据只在服务器解密后提供给只读 SMB 组件，不进入模型提示词或客户端。技能目录只提供必要元数据，不加载和执行所有技能正文。

## 客户端与服务器更新

Mac mini 备份并部署本版服务器包后，已有客户端重新打开即可加载这次界面和业务更新。Windows 可从左下角下载校验并安装 0.32.0；Mac 使用对应架构 DMG。客户端安装包不会自动替换服务器代码。员工的项目和聊天继续保存在各自电脑，部署保留公司账号、部门、NAS、模型配置、密钥及头像；云服务器保留业务服务并同步安装包镜像。

## 验证范围

合成数据回归覆盖技能目录与安装状态、只查询不执行技能、NAS 根目录与子目录、名称搜索、跨部门拒绝、越界路径、查询失败和进行中撤销权限。原生客户端验证真实 HTTP 流、目录追问及重新打开后的路径恢复，并确认 NAS 查询没有读取本地项目。

另使用实际配置的 DeepSeek Flash 测试 7 组语义调度，包括用户所问的两句原文、资料源查询、子目录追问、名称搜索、切换话题和平台能力查询，结果均符合样例预期。测试问题和资料源元数据均为合成数据，不使用员工文件。正式构建、部署和真实 NAS 验收结果见最终交付记录。

原创代码采用 MIT，第三方资源保留原许可，随包提供许可、隐私和签名状态说明。不含数据库、密钥、员工聊天、内部技能或开发缓存。Windows 尚无可信代码签名；Mac 为 ad-hoc 签名，未做 Apple 公证。
