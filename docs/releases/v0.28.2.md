# v0.28.2 · 工作区与对话归属

## 员工端更新

- 左侧按工作区分组显示本机对话，支持展开、收起、搜索和在指定工作区新建对话。
- 新建工作区直接打开本地文件夹选择器，使用文件夹名称作为工作区名称；取消不会新增，重复选择已有文件夹会切换到已有工作区。
- 仅在新建对话时，在输入框左上方显示简洁的工作区下拉选择。进入对话后隐藏该入口及文件夹路径，移除常驻路径卡片和顶部重复选择器。
- 新对话绑定创建时的工作区。历史对话归入默认工作区；已绑定的对话重新打开后继续使用原工作区，不随其他工作区的切换而改变。
- 工作区内的代码、素材、视频及对话导出文件，优先保存到该工作区的独立任务子文件夹。保留默认成果目录作为未选文件夹时的后备；断线续传沿用任务第一次保存的目录，不覆盖已有员工文件。

## 客户端与服务器更新

工作区界面随服务器包交付，Mac mini 部署后重开客户端可见。按工作区保存成果需要本版原生客户端，请通过左下角更新至 0.28.2；旧客户端不会冒用全局目录接收指定工作区的成果，服务端文件保留等待升级。Windows 校验后安装并自动重启；Mac 使用对应架构 DMG 替换。

服务器升级前一致性备份数据库、密钥及部署配置，沿用原有账号、部门、NAS、模型和 HTTPS 设置。Mac mini 承载业务，云服务器仅同步安装包镜像。员工文件夹路径保留在员工本机。
