# v0.11.1 · 公司更新自动分发

## 员工端更新

- 修复新版已发布、左下角却找不到更新的问题。安装包通过公司服务器提供，不需要员工访问私有 GitHub 仓库。
- 登录后自动检查，在线期间每五分钟检查，恢复联网立即重试；点击“检查更新”会获取最新状态。
- 新客户端下载中断可自动重试和续传，下载完成及安装前分别核对完整性。
- 升级保留公司连接地址、本地对话及个人草稿。Windows 在应用内下载后点“退出并安装”；Mac 打开安装包后按提示替换应用。

## 下载与更新

Windows x64：`Corporate-Brain-Setup-0.11.1-x64.exe`；Mac：`Corporate-Brain-0.11.1-macOS-arm64.dmg` 和 `Corporate-Brain-0.11.1-macOS-x64.dmg`；公司服务器：`Corporate-Brain-Server-0.11.1.zip`。

管理员备份后部署服务器包，配置安装包镜像目录及专用发布账号，见 `docs/UPDATE-DISTRIBUTION.md`。完成服务器配置后，0.9.0 等既有客户端可通过原更新接口直接发现本版，无须先手工安装过渡版。客户端安装本版后获得续传、公司地址保留改进；界面与检查节奏由公司服务器提供。

## 发布分发与验证

发布流程增加公司分发检查：GitHub 完整 Release 公开后，三种客户端安装包自动上传公司服务器，逐个校验大小及 SHA-256，完整后原子切换；失败保留旧版并让工作流报错。同版本不可改写，拒绝降级，保留最近三个版本供下载。专用发布密钥禁止 shell、端口转发和修改业务目录；不向公司服务复制个人 GitHub token。

检查覆盖认证、旧接口兼容、Range 续传、损坏文件、缺失/截断/多余数据、摘要不符、路径攻击、重复发布和拒绝降级。Windows 隔离 runner 使用真实 0.9.0 安装包验证升级和记录保留；Windows、两种 Mac、服务器的实际报告和 SHA-256 随 Release 提供。生产分发与旧版客户端下载证据单独记录于仓库交付报告。

离线或未打开的客户端会在恢复联网并登录后检查，不能据此声称所有员工已经安装。Windows 仍未取得可信代码签名；Mac 为 ad-hoc 且未公证；安装需员工确认。原创代码 MIT，第三方许可保留，SignPath 尚未获批。

0.11.0 为未公开候选草稿：Mac 验收原先假定所有包都没有公司地址，与本次预配置行为冲突。本版修正验收，核对真实包内公司地址，并使用隔离公司页面验证原生配置入口；重新执行完整构建，不覆盖旧标签或包。
