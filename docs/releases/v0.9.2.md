# v0.9.2 · DSH / DeepSeek 对话加载项

## 员工端更新

- 将对话里的 Grok Ball 和四步横向流程卡片替换为 DSH / DeepSeek 样式：鲸鱼标识、当前模型名称、小型旋转状态环、扫光文字与本轮等待时间。
- 准备本机上下文时显示“正在准备上下文”；提交对话后显示“正在思考”，图片请求显示“正在生成图片”。状态跟随请求生命周期，不再按定时器模拟分析、工具调用或完成步骤。
- 修复完成卡片长期残留的问题。成功后由回复接替加载项，失败后显示错误；新建或切换对话不会带入其他对话的加载和错误信息。
- 暖色、深色、窄窗口和系统减少动态效果设置均已适配。启动页与登录页继续使用 0.9.1 的动效，本次修改的是对话区域。

## 可播放预览

`artifacts/previews/chat-loading-0.9.2/index.html` 可直接打开，支持明暗切换及模拟回复完成；同目录提供 MP4 和静帧。预览使用实际组件生成，示例文本不连接公司服务器。

## 下载与更新

- Windows x64：`Corporate-Brain-Setup-0.9.2-x64.exe`。
- Apple 芯片 Mac：`Corporate-Brain-0.9.2-macOS-arm64.dmg`。
- Intel Mac：`Corporate-Brain-0.9.2-macOS-x64.dmg`。
- 公司服务器：`Corporate-Brain-Server-0.9.2.zip`。

客户端从公司服务器加载对话界面。管理员备份后更新服务器包，员工重启客户端即可加载本次界面修复；安装 0.9.2 客户端可同步本地版本和法律声明。服务器更新继续使用原数据库与加密密钥，不覆盖员工本机记录。

当前公司私有仓库更新源尚未启用，本次提供本地安装包手动更新。
