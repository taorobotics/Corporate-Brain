# v0.2.0 公司大脑测试版

## 员工端更新

- 左侧底部新增更新图标；发现新版时显示版本提示，点击查看更新说明。
- 登录后自动检查，运行期间每 30 分钟检查；重新联网或回到窗口时按节流策略复查，也可在“帮助”和账号菜单手动检查。
- 自动匹配 Windows、Apple 芯片 Mac 或 Intel Mac 安装包，显示下载进度，支持取消、重试和稍后安装。关闭弹窗后仍可继续工作。
- 下载完成后校验安装包大小与 SHA-256，安装前再次核对并保存本地记录。Windows 打开安装向导；Mac 打开 DMG，由员工拖入 Applications 替换。
- 原有客户端加载新版公司网页后可通过过渡入口下载新版安装包，手动安装一次后启用完整更新流程。更新不清空本地对话或个人草稿。

## 下载和部署

从 Assets 选择 Corporate-Brain-Setup-0.2.0-x64.exe、Corporate-Brain-0.2.0-macOS-arm64.dmg 或 Corporate-Brain-0.2.0-macOS-x64.dmg；公司服务使用 Corporate-Brain-Server-0.2.0.zip，校验文件为 SHA256SUMS.txt。

管理员需要先更新公司服务。客户端从公司服务器加载网页，只更新桌面安装包不会升级服务器。停止服务并一致性备份原 .data（含 secrets.key）和部署配置，将服务器包解压到新的应用目录，执行 npm ci --include=dev，继续指向原 BRAIN_DATABASE 和 secrets.key，保留原 HTTPS、APP_ORIGIN、HOST、PORT 配置后 npm start。服务器包含预构建 dist，无须重建；不得覆盖、清空原数据库。

当前 GitHub 仓库为私有。服务器启动环境新增 BRAIN_GITHUB_TOKEN，建议使用仅授权 taorobotics/Corporate-Brain、Contents: read 的 fine-grained token。只在服务器的部署密钥中保存，不写进源码、客户端或聊天，不要求员工提供 GitHub 账号。未配置时界面明确提示尚未启用更新。详见 docs/DEPLOYMENT.md。

管理员部署服务后，员工重新打开客户端即可载入更新入口。0.1.x 客户端先手动安装本次新版；0.2.0 起可通过客户端检测、下载并打开后续安装包。当前采用用户主动安装，不会静默退出、替换程序或自动更新公司服务器。

## 验证与限制

本次包含数值版本比较、防降级、三种平台选择、成功下载与缓存复核、取消清理和重试、损坏与截断拒绝、私有源授权、令牌与重定向隔离、未配置与错误状态测试。原部门账号和 Skill 流程继续覆盖。原生工作流运行前端生产构建、17 项测试、Windows 21 项 / Mac 20 项桌面交互检查，再构建并核对各安装包；结果以随 Release 提供的真实报告为准。

桌面更新链路在隔离服务中使用明确标注的惰性安装包素材验证下载、校验和状态，不运行测试安装程序，不访问实际员工数据。真实发布源的读取与资源摘要单独复核。Windows 尚未做可信签名；Mac 只有 ad-hoc 签名、没有 Developer ID 或 Apple 公证，更新入口不会消除系统提示。独立员工设备上的真实覆盖安装、Gatekeeper、升级与卸载仍需验收。
