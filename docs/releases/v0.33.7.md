# v0.33.7 · 降低后台更新的资源竞争

## 员工端更新

- Windows 安装文件直接解压到专用准备目录，省掉原先从 `7z-out` 再完整复制到 `prepared-app` 的步骤。准备完成后才替换旧版，仍保留取消、失败检查和个人数据保护。
- Windows 后台自动更新降低 CPU、磁盘及内存调度优先级，让前台工作优先使用资源。原生更新交接及旧客户端从更新缓存启动两条路径均适用。
- 安装完成后先恢复正常调度，再自动重启公司大脑，避免新客户端继承后台安装的低优先级。

这是减少复制量与资源竞争的优化。具体耗时仍与磁盘、杀毒扫描及同时运行的软件有关；不承诺固定耗时或完全无卡顿。

## 客户端与服务器更新

更新到 0.33.7 的 Windows 安装包即可使用新流程，包括首次从旧版升级到本版。后续后台更新同样适用；Mac 沿用 DMG 更新方式。

服务器包与客户端版本同步提供 0.33.7，本次安装器优化无需重启业务服务器或重新部署界面。Mac mini 与云端更新源同步新版安装包，客户端仍使用原公司地址和安装目录。管理员另行更新服务时须备份并保留原数据库、密钥及配置；公开包不含公司数据。

## 验收与许可

原生验证检查直接 7z 解压后的文件摘要、取消与超时保护、旧版升级、后台更新进程的实际 CPU/I/O 优先级、重启后客户端的正常调度，以及快捷方式与个人数据保留。正式 Release 随附三平台安装包、服务器包、SHA-256 和真实检查记录。

原创代码采用 MIT，第三方许可与隐私说明随包保留。Windows 尚未可信签名；Mac 为 ad-hoc 签名、未公证。

## 最终交付记录

195 项 Node 测试、8 项 NAS 协议测试、生产构建、Windows 本机 8 项原生更新交接与资源检查、5 项安装向导检查通过。实测两种自动更新入口的安装进程 CPU 类别为 BelowNormal（16384），I/O 为 VeryLow（0）；重启后的客户端为 Normal（32）和正常 I/O（2）。真实 7z 归档直接解压后的 SHA-256 一致，未创建中间 7z-out 目录。

三平台正式构建与验收通过。Windows 有 61 项完整桌面、20 项真实安装升级卸载与数据保留、8 项更新交接检查；两种 Mac 的实际挂载与启动检查通过。Windows 本机完整桌面套件因已确认的系统剪贴板访问问题未重复运行，正式 CI 未跳过复制验收。13 项 Release 资源均完整下载并核对摘要。

本地应用文件约 376.5 MiB，去掉一整轮复制后，应用有效载荷的逻辑写入量由约三份降为两份，每次少写约 376.5 MiB。这不是物理磁盘计数或耗时提升比例；未复现并采样用户当时的整机卡顿，也不承诺完全消除杀毒扫描等影响。

Mac mini 安装包与更新源已同步为 0.33.7；业务服务保持 0.33.6，监听进程未重启，严格 HTTPS 与 224 个账号、13 个部门、14 个 NAS 来源、3 个普通技能的计数核对通过。真实 0.33.6 更新模块在三平台完整下载并校验新版至待安装状态，没有强制安装员工设备。云端安装包镜像为 0.33.7，原 0.11.6 业务服务保持健康。
