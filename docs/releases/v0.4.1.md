# v0.4.1

## 本机记录读取修复

- 修复 Windows 客户端在“正在读取本机记录…”页面长时间无响应的问题。
- 桌面端验证当前账号的公司服务请求增加 10 秒超时；已有本机验证状态时仍可按原规则离线读取。
- 本地记录读取失败时显示明确原因和“重新读取”按钮，不再无限停留在加载状态。
- 浏览器 IndexedDB 打开和读取同样增加超时保护。
- 本机记录写入等待异常时会及时提示，不阻塞后续读取。

## 验证

- `npm run build`：通过。
- `npx tsx --test server/dsh.test.ts`：2 项通过。
- 云端 DSH 真实请求：HTTP 200，返回 `DSH_PERMISSION_OK`，实际 Token 用量正常返回。
- 云端服务健康检查：通过。

## 部署

- 公司服务器已直接更新本机 DSH 运行目录权限，并加入 systemd 启动前权限校正；不需要重新填写 API Key。
- 员工端网页由公司服务器提供，刷新或重新打开客户端即可获得读取超时和重试界面。
- 本次按当前要求暂不推送 GitHub；Windows 安装包和服务器包在本地构建后再交付。
