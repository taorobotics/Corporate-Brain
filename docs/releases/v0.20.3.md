# v0.20.3 制作任务回到普通对话

## 员工端更新

- 视频、代码等制作任务沿用普通对话的回复与处理过程，移除独立制作面板、五步清单及百分比进度条。没有固定的“思考 → 执行 → 输出”展示模板，回复内容由模型按任务组织。
- 制作请求使用流式响应，取消对 DeepSeek 思考的强制关闭；只显示模型实际提供的思考内容，未执行的步骤不提前展示，模型未提供思考时不补写。
- 模型回复与实际工具记录同步保存在该员工的本机对话中，可继续复制、反馈和查看历史。代码、素材及成片的本机自动保存、校验、服务器清理、失败重试和成品预览保留。

## 客户端与服务器更新

本次同时更新服务器网页和制作服务。管理员一致性备份后升级 Mac mini，保留原账号、部门、NAS、技能、模型密钥和 HTTPS 配置；连接该服务器的客户端退出后重新打开即可使用新版界面。Windows 安装包按原目录后台更新并自动重启，Mac 使用对应架构 DMG。

局域网独立构建的安装包默认连接 Mac mini；GitHub 正式包使用公司发布地址，已有客户端保留选定服务器。云端只同步安装包镜像，本次不升级旧云业务服务。

## 验证范围

检查流式思考在生成完成前到达、真实回复与工具历史保留、未执行步骤不出现、普通 Markdown 回复无制作面板、失败与原对话重试，以及完整文件校验和自动清理。运行现有类型检查、生产构建、单元测试、桌面交互与各平台安装检查；Mac mini 另核实际视频渲染和本机成片预览。部署及分发结果见下方实际检查记录。

## 实际检查与部署记录

- Windows 和 Mac mini 均通过 93 项 Node 测试、5 项 NAS 工作进程测试、类型检查与生产构建；Windows 桌面 41 项、Mac 桌面 40 项、各自启动 9 项检查通过。
- 制作交互验收在 Windows 通过 4 项、Mac 通过 5 项，确认实际模型思考先于生成完成到达、回复与思考记录保存在员工本机且重载后仍在，失败可在原对话重试。Mac 实际制作并预览了 2 秒、1280×720 的视频，所有源码、素材及成片完整保存并核验后清理服务器文件；另通过 3 秒、72 帧的带音频渲染检查。验收使用隔离合成模型与素材，不消耗生产模型额度。
- 正式 GitHub Windows 环境通过 17 项实际安装、升级、自动重启、卸载及数据保留检查、5 项原生更新交接检查。两种 Mac DMG 均通过挂载和首次启动检查；正式 Release 的 13 项资源及四个包的校验值已核对。
- 本机第一次桌面检查在原有的窄窗口过程高度断言处失败；顺序完整复跑同一验收工具通过，正式三平台桌面检查也全部通过，未放宽断言或替换产品标签。

- 局域网 Windows x64 和 Mac arm64 更新通道已启用 0.20.3，并通过临时验收账号完整下载及 SHA-256 校验，随后删除该临时账号并核对原账号未变。GitHub 发布与公司分发工作流全部成功；云端三个平台的安装包已完整同步，并独立读取文件核对大小与 SHA-256，与正式 Release 一致。旧云业务服务本次不升级。
