# v0.13.0 · 可视化技能导入

## 员工端更新

- 技能中心新增“导入技能”：粘贴公开 GitHub 仓库或技能目录链接，或者上传 32MB 以内的 ZIP。
- 先预览技能入口、正文、文件、许可与发布范围。普通员工提交审核，公司管理员可确认后直接上架；同一份包不会重复导入。
- 保留引用资料、脚本和各自许可，GitHub 来源固定到具体提交并逐文件核对摘要。导入不执行安装脚本、不自动安装系统软件。
- 配套资源由公司服务器保存；使用时重新核对当前员工权限和发布状态，放入当前员工的独立任务工作区。管理员停用技能后，旧的本机安装记录不能绕过检查继续运行。
- 已安装列表支持移除；卡片摘要限行，完整正文、许可与运行条件可在详情查看。

## 本次接入的项目

- Lemo-Opuscar：文库版，保留核心工具、风格手册与许可，不重复下载展示网站、海报和演示片源码。未执行上游 setup 脚本。
- MG Styles 15：原项目没有 SKILL.md；新增公司大脑流程入口，保留原提示词、示例源码、渲染器、素材与许可，不下载展示成片和网站。
- 花叔 Design：保留原始 SKILL.md、引用资料、脚本、样张及许可。

这三个仓库的根许可均为 MIT，附带第三方素材继续遵循各自许可。技能导入与渲染环境是两件事：浏览器、Python、FFmpeg、Blender 等能力仍需根据任务验证；本次没有宣称生成视频、没有自动安装系统依赖。

## 更新与数据边界

Mac mini 需要部署服务器包才能提供界面和导入接口。原有客户端重新打开即可加载新界面，Windows 与 Apple 芯片 Mac 的客户端安装包另同步到私有更新入口。

导入的公司技能资源在服务器数据库目录旁的 `skill-library` 保存，应与数据库一起备份；不是程序安装包的一部分，不进入 GitHub 或公开 Release。员工原有聊天仍在各自本机。NAS 配置准备文件不读取、不上传。

GitHub 按此前要求继续暂停。本次为私有局域网交付，Intel Mac 没有新安装包，保持原通道；Windows 未可信签名，Mac 为 ad-hoc 签名、未 Apple 公证。未在员工设备执行自动覆盖安装或卸载。

## 检查

新增 ZIP 路径穿越、符号链接、重复路径、解压限额与损坏校验；GitHub 地址边界、固定提交和 blob 完整性；登录、预览所有权、部门权限、审批、去重、资源篡改与停用检查。真实 Electron 验证 GitHub 预览、ZIP 上传、确认、上架、提交审核和深色窄窗口。交付记录标明实际通过的检查和范围。
