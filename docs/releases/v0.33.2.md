# v0.33.2 · 修复模型版本追问与对话调度中断

## 员工端更新

- 修复“您好，我现在用的什么模型呢？”及后续“版本是多少啊？”“？？版本号多少啊？”被智能调度拦住、没有任何文字回答的问题。此类问题现在直接读取本轮所选模型配置，切换模型后按新配置回答，不依赖供应商连接、技能或项目文件扫描。
- 回答明确区分当前配置的模型标识与供应商内部实际运行版本，不凭名称冒充独立核验结果，也不将模型版本说成客户端版本。
- 调度返回普通文字、空内容或不合法的任务结构时，安全退回普通文字回答；不自动创建制作任务、不执行未验证的技能或文件工具、不扫描本地项目、不重用历史附件。
- 调度兼容 JSON 与 SSE 响应，优先请求 JSON 格式；明确不支持该参数的接口可退回兼容请求。只读调度遇到连接重置最多重试一次，共用原处理期限；认证失败不会盲目重试。
- 公司知识、NAS 正文分析、图片技能与代码/视频制作仍须通过原有授权和有效任务校验，权限边界保持生效。

## 客户端与服务器更新

本次修复在公司业务服务中，管理员应备份并部署本版服务器更新包；连接 Mac mini 的员工重新打开客户端即可加载更新。桌面安装包和左下角自动更新同步发布为 0.33.2，Windows 沿用原目录安装，Mac 使用对应架构 DMG。只升级桌面安装包不会替换服务器业务。公司账号、部门、NAS 权限、模型配置和密钥继续保留。
