# 公司大脑 0.17.3

## 员工端更新

- 对话回答下方移除重复的反馈问题图标，保留拇指向下的反馈入口。操作栏依次为复制、拇指向上、拇指向下和分享。
- 点击拇指向下仍可选择评价、问题类型并填写说明，反馈继续送达管理后台。已有问题反馈仍显示选中状态，重新打开时保留原评价和说明。

## 客户端与服务器更新

本次为服务器网页界面修复。Mac mini 更新后，员工关闭并重新打开客户端即可加载新操作栏；已有客户端无需重装即可使用。本版客户端安装包用于版本同步及新设备安装。更新前一致性备份，保留账号、部门、NAS、技能、模型设置和密钥。
