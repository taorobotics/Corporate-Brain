# v0.33.8 · 左侧头像菜单与统一意见反馈

## 员工端更新

- 头像移到最左侧导航栏底部，折叠对话列表后仍可使用。点击头像展开“设置、反馈、退出登录”。原对话列表底部的重复账号、设置和更新入口移除。
- 最左侧头像上方仅在发现可用更新时显示更新图标，下载和待安装状态可继续查看进度。没有更新时隐藏；手动检查仍可从顶部“帮助 → 检查更新”打开。
- 头像菜单新增独立意见反馈入口，可提交界面、操作、对话或任务问题。只发送填写的内容，不自动附带聊天记录或文件。
- 管理后台统一为“用户反馈”，整体使用反馈与回答评价进入同一张表，可按来源筛选并沿用原有处理流程。具备管理权限的账号可从“设置 → 公司管理”进入管理后台。

## 客户端与服务器更新

客户端安装包与服务器包均为 0.33.8。界面由公司服务器加载，管理员必须部署本版服务器包才会显示新布局和新增反馈入口；仅安装新版客户端不会替换服务器网页。Mac mini 是本公司的主要部署目标，安装包和更新源一并同步。云端安装包镜像沿用现有分发流程。

部署前停止本项目服务并一致性备份数据库、密钥和配置，保留原账号、部门、NAS 和模型配置。本版对既有反馈增加来源字段，原回答反馈自动标记为回答来源，不删除或重写原记录。

## 验收与许可

验收覆盖头像菜单、折叠侧栏、无更新状态隐藏图标、更新下载与安装入口、整体反馈提交与后台汇总，以及原有账号、聊天和设置导航。正式 Release 随附 Windows x64、Mac arm64/x64 安装包、公司服务器包、SHA-256 和三平台实际检查记录；以随包检查文件为实际通过范围。

原创代码采用 MIT，第三方许可和隐私说明随包保留。Windows 尚未可信签名；Mac 为 ad-hoc 签名、未公证。

本地生产构建、196 项 Node 测试、8 项 NAS 协议测试、62 项完整桌面交互检查和账号资料检查通过。新入口已实际提交隔离反馈，并核对后台明细、来源、无聊天上下文及文本安全显示；无更新状态、折叠侧栏、深色窄窗口和原有更新下载校验均已检查。
