# v0.5.0

## DSH 任务阶段与加载动画

- 对话请求期间新增可直接查看的任务阶段：接收任务、分析任务、读取附件/检查工具和整理回复。
- 阶段会根据当前 DSH 模式、附件和请求结果更新状态，并在成功或失败时显示完成/错误状态。
- 明确标注这是任务阶段，不展示模型隐性思维内容；不会把模拟状态包装成真实思考链。
- 加入 Grok Ball 加载动画，使用 `tycoding/grok-ball` 的 MIT 许可实现，固定上游提交并保留源码与许可证。
- Grok Ball 的表情状态与接收任务、分析、检索、生成、完成和错误状态对应。
