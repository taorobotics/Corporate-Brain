# v0.9.1 · 完整启动、加载与登录动效

## 员工端更新

- 完整替换旧版“公司大脑 / 正在连接公司工作空间”的静态等待页。客户端启动、网页连接、账号登录、登录验证、本机记录读取和欢迎揭幕使用同一套 DSH 技术档案风格场景。
- 新增标识序幕、光幕揭示、档案面板展开、环形准星与线框标识、登录面板入场、欢迎文字色散和分片揭幕。登录仍使用真实公司账号；不会播放虚假的授权或验证成功状态。
- 默认暖色；设置里选择深色后，启动、加载和登录界面一起变为深色。皮肤中心仍保留原来的 62 款工作区皮肤。
- 跳过动画和 Escape 可快速结束开场；窗口控制、断线重试、登录错误提示及系统减少动态效果设置均保留。欢迎揭幕期间阻止对背后工作区的误操作。
- 修复此前启动页结束后又跳回旧加载样式的问题；网页接续本地启动时间，不从头重复播放开场。

## 可播放的视觉预览

源码的 `artifacts/previews/entry-0.9.1/index.html` 可直接在本地浏览器打开，支持播放、暂停、重播、拖动进度、暖色及深色切换。同目录包含暖色和深色 MP4，以及登录、连接、序幕与欢迎的静帧。

预览使用与客户端相同的场景代码。视频中的账号和最终工作区为演示内容，不会连接公司服务器；实际连接和账号验证的等待时长由网络及服务器决定。场景为实时网页动效，不是启动时下载或播放一段视频。

## 下载与更新

- Windows x64：`Corporate-Brain-Setup-0.9.1-x64.exe`。
- Apple 芯片 Mac：`Corporate-Brain-0.9.1-macOS-arm64.dmg`。
- Intel Mac：`Corporate-Brain-0.9.1-macOS-x64.dmg`。
- 公司服务器：`Corporate-Brain-Server-0.9.1.zip`。

管理员需更新服务器包以替换网页加载和登录界面；员工需安装新版客户端以替换本地启动动画并获得连续时间线。仅重开旧客户端或只安装客户端，不能替换服务器上的旧网页。原账号、部门、模型密钥和员工本机记录保留。

当前公司部署的私有仓库更新源尚未启用，员工本次需手动安装管理员提供的安装包。发布 GitHub Release 不代表公司更新源已自动配置。

## 验证与分发

版本检查、30 项后端测试、TypeScript 与生产构建、真实 Electron 的启动恢复及桌面交互检查由本地和发布工作流执行。桌面检查涵盖加载与登录同一场景、开场自动结束、欢迎揭幕结束后可操作工作区、错误重试、账号隔离、明暗切换和窗口控制。Windows 临时 CI 环境执行安装、升级、卸载及数据保留测试；Mac arm64 和 x64 原生环境分别构建与检查。真实检查报告及 SHA-256 随 Release 提供。

更新服务器前停止服务并备份 `.data`、`secrets.key` 及部署配置，将服务器包解压到新目录，复用原数据库和密钥路径，切换后检查 `/api/health`，失败时切回旧目录。包中不含数据库、员工记录或凭据。
