# v0.2.7

## 员工客户端登录入口

- 员工桌面客户端不再显示服务器地址输入框，也不提供注册或初始化入口。
- 管理员在打包时设置 `BRAIN_APP_URL`，安装包会预置公司服务入口，员工打开后直接进入公司账号登录页。
- 未预配置入口的测试包会显示“公司大脑未配置”，明确提示联系管理员获取正确安装包。
- 服务器切换和入口配置仅保留给验证或管理员配置环境，普通员工菜单不显示该项。
- 配置页不保存账号、密码或密钥，预置文件只包含服务 URL。

## 安装流程

- 安装器阶段刷新调用已补齐，准备、写入、注册和完成检查前会立即刷新进度页。
- 写入阶段文案改为“替换旧版并写入程序”，与实际操作一致。

## 验证范围

- `npm run version:check`
- `npm test`
- `npm run build`
- `npm run test:desktop`
- Windows 安装器验证与发布资源校验在打包完成后补充到本版本报告。
