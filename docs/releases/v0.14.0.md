# v0.14.0 · 部门 NAS 目录浏览

## 员工端更新

- “公司知识”接通本部门获准的 NAS 资料源，支持目录层级、返回上一级、当前目录名称搜索和文件信息。
- 文件内容预览、下载、AI 读取和写入归档尚未开放。目录浏览不修改 NAS 文件，也不会将资料内容发送给模型。
- 深浅色界面、窄窗口、读取进度、空目录、权限不足与连接失败提示。

## 管理后台

- 配置 NAS 内网地址、共享和子目录、各部门账号、允许浏览的公司部门与启用状态。
- 密码加密保存在公司服务器；编辑时留空保持原值，客户端不获得密码。提供真实连接检查和状态。
- NAS 原有权限不变。公司管理员可管理配置，读取资料仍需获得所属部门授权；停用资料源、停用员工或撤销部门授权会阻止后续及正在等待的目录结果。

## 部署与检查

先更新服务器程序，并按 `docs/NAS.md` 在本项目目录配置固定版本的 Python SMB 连接依赖，NAS 需支持 SMB 3 加密。已有客户端重新打开即可加载新界面；Windows 与 Apple 芯片 Mac 的 0.14.0 安装包同步至 Mac mini 私有更新入口。

真实部门、员工归属、NAS 凭据和连接结果属于公司部署数据，不包含在服务器 ZIP、客户端安装包或 GitHub 源码中。原有账号、模型、技能资源和员工本机聊天保留。

验收覆盖路径边界、部门隔离、密码密文、请求过程中的撤权、会话退出、连接限流及目录链接阻断；真实界面检查配置、连接检查、目录导航、文件信息、搜索和深色窄窗口。实际公司 NAS 的可连接数量与待核对项另记私密交付记录。

GitHub 按此前要求继续暂停；本次为私有局域网交付。Windows 未可信签名，Mac 为 ad-hoc 签名且未 Apple 公证；Intel Mac 保留原通道。未在员工电脑执行覆盖安装或卸载，云服务器保留。
