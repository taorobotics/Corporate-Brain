# v0.10.1 · 思考过程中的来源链接

## 员工端更新

- 补齐 0.10.0 思考过程的来源打开行为：点击来源或回答里的网页链接，会交给系统默认浏览器，保持公司大脑对话窗口不变。
- 拒绝非 HTTP/HTTPS 协议、带账号密码或过长的地址，外部页面不会进入客户端的授权窗口。
- 包含 0.10.0 的实时思考正文、实际工具与搜索来源、可折叠过程区、Grok-ball、停止生成及本地过程保存。没有公开思考字段的模型继续如实显示等待或未提供思考内容。

## 下载与更新

Windows x64：`Corporate-Brain-Setup-0.10.1-x64.exe`；Mac：`Corporate-Brain-0.10.1-macOS-arm64.dmg` 和 `Corporate-Brain-0.10.1-macOS-x64.dmg`；公司服务器：`Corporate-Brain-Server-0.10.1.zip`。

本次外部链接修复属于桌面程序，员工需要安装新版客户端。思考过程界面与服务由公司服务器提供，管理员备份数据库、加密密钥和配置后部署对应服务器包。原有账号与本机记录继续保留。公司私有仓库更新源未配置时，请手动安装交付包。

0.10.0 已发布，不覆盖其标签和安装包；0.9.2 仍保留为被替代的未公开草稿。

## 验证与限制

执行 35 项后端与共享逻辑测试、类型检查、生产构建和真实 Electron 交互验收。新增来源点击检查：验证系统浏览器调用、原客户端窗口保留，以及非网页协议和带凭据链接的拒绝；测试拦截系统浏览器调用，不打开真实外部网页。Windows、两种 Mac 和服务器的实际报告及 SHA-256 随 Release 提供。

0.10.0 云端已通过 DeepSeek Flash 与 Pro 的短问题实测，两者均在完整回答之前返回了公开思考内容；本补丁不改变该传输逻辑。没有推断其他供应商一定提供思考，也没有制造工具或搜索活动。

思考与 Grok-ball 的演示位于 `artifacts/previews/chat-loading-0.10.0/`，素材明确标注为演示。原创代码采用 MIT，Grok-ball 与 DSH 等第三方保留原许可。Windows 未取得可信代码签名；Mac 为 ad-hoc 签名且未经公证；SignPath 尚未获批。
