# v0.8.3

## 员工端更新

- Windows 客户端登录页右上角补齐最小化、最大化／还原、关闭按钮，顶部空白区域可拖动窗口。
- 正在连接、连接失败、退出登录和管理后台也保留窗口按钮，不再需要先登录才能管理窗口。
- 窗口按钮增加按压反馈，关闭按钮悬停时显示红色；最大化后图标与提示切换为“还原窗口”。
- macOS 保留系统原生窗口按钮，网页端不显示桌面专用按钮。

## 更新方式

- 本次登录页修复随公司服务器更新包交付。管理员备份后部署服务器包，已连接公司服务器的 Windows 客户端重新打开即可加载新界面。
- 同时提供 Windows x64、macOS arm64 / x64 安装包；新版桌面程序还修正从全屏状态点击“还原窗口”的行为。
- 服务器升级继续使用原有数据库、连接配置和账号；不清除本机对话与个人草稿。

## 检查与分发

- 真实 Electron 窗口检查登录前的最小化、最大化、还原与关闭事件；检查管理后台、退出登录、连接中、服务器异常回复和重试后的按钮。
- 后端和共享逻辑测试、生产构建、原有桌面交互检查；各平台安装包与 Windows 安装升级卸载检查记录随 Release 提供。
- Windows 尚未进行可信代码签名；macOS 使用 ad-hoc 签名，未进行 Apple 公证。
- 安装包和服务器包不包含账号密码、公司数据库、模型密钥或员工记录。
