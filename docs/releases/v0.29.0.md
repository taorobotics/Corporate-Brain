# v0.29.0 · 多对话并行执行

## 员工端更新

- 修复一个对话运行时，新建对话无法发送的问题。不同对话可以同时执行，各自保留加载内容、回答、错误和中止状态。
- 停止一个对话只中止它自己的请求或任务，其他对话继续运行；后台先完成的回答会写回原对话。
- 切换对话时，各自的未发送草稿、附件解析和原始素材保持独立，同名附件不会跨对话混用。新建对话的输入框保持独立。
- 执行中发送补充要求后，可以切换到其他对话；补充要求仍在原对话续发，不会误发到当前窗口，也不会清空当前草稿。
- 退出登录会清理仍在连接的对话请求；重新登录不会继承旧的加载状态或发送锁。

## 客户端与服务器更新

界面随服务器包交付，Mac mini 备份更新后，已有客户端重新打开即可使用。桌面安装包同步更新至 0.29.0，Windows 可从左下角检查更新、校验后安装并自动重启，Mac 使用对应架构 DMG 替换。

Mac mini 保留原数据库、账号、部门、NAS、技能、模型密钥及 HTTPS 配置。云服务器只同步客户端安装包镜像，原业务服务保持运行。

普通对话可并行；视频和代码制作继续遵守 Mac mini 现有队列、磁盘及任务配额。排队不会锁住其他对话的发送，不表示所有视频同时占用渲染资源。切换对话时在线请求继续，退出登录或关闭客户端会中断尚未完成的在线连接；本机保存成果继续保留。
