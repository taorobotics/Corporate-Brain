# v0.27.4 · 对话图片展示与本地成果快链

## 员工端更新

- 对话成果保存后，GIF、PNG、JPEG、WebP 自动显示在原回复中，无须先展开文件列表；点击图片可放大，GIF 保留动效。
- “已保存到本机”的路径可直接点击，打开当前成果文件夹。压缩包、说明和源文件提供快捷入口；点击文件名可在系统文件管理器中定位对应文件。
- 图片从当前员工已保存的本机成果读取，沿用文件大小、摘要与账号校验，不重新生成或上传。仅在接近可见区域时读取，默认展示最多 8 张、单张 8 MB、合计 32 MB 以内的图片，其余文件保留在完整列表中。
- 放大预览支持关闭按钮、Escape 和键盘焦点管理；浅色、深色及窄窗口保持可读。旧客户端保留打开成果文件夹的入口，升级后可使用文件精确定位。

## 客户端与服务器更新

网页界面需要更新公司服务器包并重新打开客户端；文件精确定位需要同时安装本版桌面客户端。Windows 通过左下角检查更新，下载校验后点击安装，沿用原目录并重启；Mac 使用对应架构 DMG 替换，保留已配置的公司服务器地址。

管理员升级前停止服务，备份原数据库、密钥和部署配置，解压公司服务器包，沿用原数据与 HTTPS 配置启动。本轮不更换模型、技能或 DSH 执行内核，也不修改员工文件和账号配置。

## 验证与边界

本版包含 v0.27.3 未公开草稿的成果展示功能，并修正跨平台验收中新增文件链接后的按钮定位，使用真实外观设置检查深色效果，截图采集进行有限重试；各项功能、视频解码和截图检查均保留，没有跳过验收。

验证包括本地文件入口的账号限制、未登记文件和路径穿越拒绝、链接目录拒绝，以及原生客户端的自动 GIF 展示、放大预览、文件夹与文件定位调用、刷新后保留成果关联。文件管理器调用在隔离验收中截获，避免打开实际系统窗口；测试素材与接口均为合成数据，不能当作真实模型生成质量测试。

本地 Windows 已通过 147 项 Node 测试、5 项 NAS 测试、生产构建及 5 项原生成果回传检查，确认浅色与深色窄窗口中的自动图片解码、快链目标和刷新恢复。各平台完整安装与启动验收以 Release 中对应报告为准。

Mac mini 也已完成本版构建及 6 项原生成果检查，包括 2 秒、1280×720 视频的实际渲染、保存与本地解码，以及自动 GIF 展示、文件快链、真实深色设置和刷新恢复。
