# v0.27.6 · 显眼的项目文件夹入口

## 员工端更新

- 在对话输入框上方常驻显示“项目文件夹”。未选择时显示用途说明与“选择文件夹”按钮；选择后显示本机路径和“更换文件夹”，不再需要寻找顶部的小图标。
- 路径过长时省略显示，鼠标停留可查看完整路径；入口随浅色、深色皮肤变化，窄窗口仍保留文字按钮。
- 将原“工作区”选择改为“切换项目”，“默认工作区”改为“默认项目”，权限入口改为“项目权限”。已有项目名称、文件夹与权限继续保留；取消选择不会清空原路径。
- 项目文件夹供 AI 读取本机资料；成果自动保存位置仍在设置中单独配置，二者用途不同。

## 客户端与服务器更新

本次界面随公司服务器包交付。Mac mini 备份并部署后，已有客户端重新打开即可看到新入口；桌面安装包同步递增为 0.27.6。Windows 可通过左下角检查更新、下载校验后点击安装，沿用原目录自动重启；Mac 使用对应架构 DMG 替换。首次安装填写公司提供的 HTTPS 地址。

管理员部署前一致性备份原数据库、密钥与配置，沿用现有账号、部门、NAS、模型和 HTTPS 设置。Mac mini 承载业务，云服务器仅同步安装包镜像。

## 验证范围

检查覆盖项目名称兼容、原生目录选择桥接、取消与更换、路径持久化、AI 实际读取选定目录，以及真实深色设置和窄窗口下的显示。目录与模型测试使用隔离的合成资料，不读取员工文件或调用公司付费模型。完整构建、安装和更新分发结果以本版本 Release 的实际检查报告为准。
