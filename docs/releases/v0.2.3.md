# v0.2.3 公司大脑 · Windows 安装向导

## 员工端更新

- Windows 安装改为欢迎、安装位置、安装中、完成四步向导，采用暖白界面、陶土色按钮和原生加载动画。
- 新装优先推荐固定、可写的 D 盘；没有可用 D 盘时使用当前用户目录。覆盖升级沿用原位置，不搬动个人对话和草稿。
- 安装页显示真实 NSIS 进度、当前操作和安装阶段，提供磁盘/权限检查、运行中提示及失败重试。解压准备期间可确认取消，实际覆盖阶段短暂禁用取消。
- 完成后可选择“立即打开”或仅“完成”；卸载界面说明保留个人记录。安装器和卸载器拒绝清除应用数据的参数。
- 临时 LOGO 使用项目已有的立方体图标，保留 MIT、隐私与第三方说明。

## 下载与部署

Windows 使用 `Corporate-Brain-Setup-0.2.3-x64.exe`。Mac 的 arm64/x64 DMG 按同版本重新构建，仍按原拖拽安装方式使用；本次没有将 Windows 向导套到 Mac。公司服务包为 `Corporate-Brain-Server-0.2.3.zip`，校验值及真实检查记录随 Release 提供。

安装目录只决定程序位置，个人记录、连接设置与更新缓存仍在原有用户数据目录；不会因为推荐 D 盘自动迁移。覆盖前应保存工作并关闭客户端。写入失败按提示重试或重新运行安装器；断电或强杀后的完整回滚不在本次承诺内。

公司网页与业务能力仍由公司服务器提供，本次主要改变 Windows 本地安装器，不新增模型、NAS、长期记忆或视频能力。管理员如更新服务器，先停止服务并一致性备份原 `.data`、`secrets.key` 和配置；在新应用目录部署服务器包、安装依赖，保留原数据库及密钥路径再启动。不得清空实际公司或员工数据。

## 验证与签名

发布前要求原有测试、前端构建、三平台 Electron 检查和打包检查通过；Windows 另在隔离 runner 实测安装前 UI、解压取消、v0.2.2 覆盖升级、记录保留、立即打开及卸载。结果以随包真实报告为准，不将本机 UI 预览冒充完整生命周期或员工物理设备验收。

Windows 仍是未签名测试包，Mac 仍为 ad-hoc，无 Apple Developer ID 或公证。安装向导不替代系统信任检查。
