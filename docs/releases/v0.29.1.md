# v0.29.1 · 取消对话固定时长限制

## 员工端更新

- 修复模型持续思考、输出或执行工具时，仍在 900 秒被公司服务器强制中断的问题。对话默认不再设置总处理时长上限。
- 修复生图接口隐藏的两分钟截止。等待图片最终结果时，不再套用聊天的无新内容计时；仍可通过输入框中止，断开客户端也会取消请求。
- 公司和个人生图接口不再受底层 HTTP 五分钟响应等待限制。连接建立、模型检查、路由、上传和本机渲染各自的保护继续适用。
- 普通聊天仍保留连续三分钟没有实际新内容时的卡死保护；空心跳和重复快照不会续命，已收到的回答继续保留。第三方模型或中转自身仍可能超时、限流、断线或达到单次输出边界，本次更新不承诺服务商无限运行。

## 客户端与服务器更新

本次修复主要位于服务器。Mac mini 备份并部署本版服务器包后，已有客户端重新打开即可使用；仅安装桌面包不会替换服务器逻辑。桌面版本同步递增到 0.29.1，Windows 可从左下角检查更新、下载校验后安装并自动重启；Mac 使用对应架构 DMG 替换。

保留账号、部门、NAS、技能、模型密钥及 HTTPS 配置。Mac mini 承载业务；云服务器只同步安装包镜像，原业务服务继续运行。

## 验证与发行说明

回归检查使用合成模型及隔离数据：虚拟时间复现旧版第 15 分钟中断，验证连续三小时有进展的默认对话不被总时限终止；验证静默生图跨过三小时虚拟时间后能完成，聊天与生图共享取消信号，中止仍能关闭实际上游请求。三小时为加速时钟测试，不代表实际调用付费模型等待三小时。实际构建、原生安装、部署和更新分发结果以本版检查记录为准。

本地 Windows 已通过 169 项 Node 测试、5 项 NAS 测试、生产构建及 12 项原生制作/对话流程检查，包含实际流式连接、中止、后台执行和账号退出清理。模型测试使用隔离的合成服务，未调用公司付费模型或读取员工素材。
