# v0.11.5 · 对话自动跟随与历史阅读

## 员工端更新

- 修复生成过程中不自动下滑的问题。思考文字、工具过程和回答持续增长时，对话自动跟随最新内容；图片加载、窗口尺寸变化也会更新位置。
- 上翻阅读历史时暂停跟随，避免新内容把阅读位置拉走。点击输入框上方的“回到最新内容”，或手动滚回底部，即可恢复跟随；发送下一条消息也会恢复。
- 思考内容统一使用主对话滚动条，移除每段思考内嵌的小滚动条，仍可展开和收起思考过程。
- 流式输出按画面刷新合并滚动，不逐字排队播放滚动动画，也不抢走输入焦点。保留键盘阅读和减少动态效果的使用方式。

## 下载与更新

Windows x64：`Corporate-Brain-Setup-0.11.5-x64.exe`；Mac：`Corporate-Brain-0.11.5-macOS-arm64.dmg` 和 `Corporate-Brain-0.11.5-macOS-x64.dmg`；公司服务器：`Corporate-Brain-Server-0.11.5.zip`。

本次修复位于公司服务器提供的对话界面。管理员备份并部署服务器包后，员工重新打开客户端即可获得修复；左下角更新入口另行提供 0.11.5 客户端安装包。只安装客户端不会替换尚未更新的服务器。独立部署的 Mac mini 需要单独部署对应服务器包，不与云端自动同步。

## 验证与分发

发布流程执行后端测试、类型检查、生产构建和三平台真实 Electron 交互检查。滚动验收使用隔离的流式事件，覆盖长思考、逐段回答、上翻暂停、回到底部、键盘翻页、延迟图片尺寸、窗口变化、切换对话、回答完成和再次发送；不调用员工模型、不读取员工记录。

Windows 执行安装、升级和卸载检查；Mac arm64/x64 检查安装包。四个交付包、SHA-256 和真实检查报告随 Release 提供，云端部署和生产更新分发另行记录。隔离测试证明相应交互行为，不代表已经逐一操作所有员工设备。
