# v0.30.0 · 外部来源制作技能与 ZIP 打包

## 员工端更新

- “制作成技能”新增三个来源入口：现有对话／手动编写、GitHub／其他链接、上传 ZIP，不必离开当前流程去找技能中心的导入按钮。
- 支持公开 GitHub 仓库、技能目录与文件链接，以及公开 HTTPS ZIP、Markdown 和纯文本下载地址。普通网页、需要登录的链接和内网下载地址会提示改用文件原文或上传 ZIP。
- 标准技能包保留技能说明、参考资料、脚本与原许可。没有 SKILL.md 但有 README 的普通项目会生成明确标注“尚未试运行”的可编辑草稿，可按需使用 AI 提炼具体流程；导入过程不执行脚本或安装依赖。
- 外部技能可编辑名称、版本、说明与流程，再试运行、确认授权并提交原有后台审核。保存草稿后可在本机继续编辑；外部文件沿用 30 分钟的临时预览机制，过期或服务重启后需重新导入，已有文字不会丢失，也不会静默省略配套文件后发布。
- 新增“导出 ZIP”：将确认的技能流程、选定示例、配套文件和原许可保存到员工本机。自行编写的技能导出标准 SKILL.md 和公司内部使用许可；不会打包完整来源对话或本机对话索引。
- 保留原有技能中心直接导入、管理员上架与员工提交审核流程。缺少原许可的外部来源可以预览和编辑，但共享发布仍需补充授权。

## 客户端与服务器更新

本次功能需要更新服务器网页和业务代码。Mac mini 备份并部署本版服务器包后，已有客户端重新打开即可使用；只更新桌面安装程序不会替换服务器。桌面版本同步至 0.30.0，Windows 通过左下角检查更新、下载校验后安装并自动重启；Mac 使用对应架构 DMG。

Mac mini 继续承载主要业务，保留账号、部门、NAS、技能、头像、模型配置和密钥。云服务器只同步安装包镜像。

## 检查范围与分发状态

本地 Windows 已完成 171 项 Node 测试、5 项 NAS 测试和生产构建。独立原生界面检查实际覆盖 GitHub 导入、本地 ZIP 上传、普通项目草稿、名称与版本编辑、草稿保存恢复、系统保存窗口导出 ZIP、文件解包检查、原许可保留、授权确认、提交审核以及深色窄窗口。测试使用隔离账号与合成项目，未执行外部脚本、调用公司付费模型或读取员工资料。

链接回归检查覆盖公开地址与每次重定向校验、内网目标拒绝、实际连接使用的 DNS 防护、临时签名参数不存入来源记录、下载大小限制、网页拒绝及 ZIP 校验。编辑导出检查同时覆盖账号隔离、个人路径／凭据拦截、原始预览不被修改、更新后的文件摘要、参考资料与原许可保留。正式构建、安装生命周期、Mac 原生检查及更新分发结果以随 Release 发布的真实检查记录为准。
