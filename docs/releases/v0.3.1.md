# v0.3.1

## DeepSeek 配置更新

- 新增 `config/deepseek.env.example`，用于填写 DeepSeek API Key；本机填写的 `config/deepseek.env` 被 Git 忽略，不进入源码、安装包或 Release。
- 公司服务器启动时自动读取 `config/deepseek.env`，也可用 `BRAIN_ENV_FILE` 指定服务器上的私有配置路径。
- 新增 `npm run deepseek:check`，只验证 Key 是否存在，不打印密钥。
- 新增 [DeepSeek 配置与部署说明](../DEEPSEEK-SETUP.md)，说明 DeepSeek Flash 视觉输入、DSH 联网搜索和服务器更新流程。

## 验证范围

- `npm run version:check`
- `npm test`（20 项通过）
- `npm run deepseek:check`（使用隔离测试 Key，输出隐藏）
- `npm run build`
- v0.3.0 已完成的 DSH 图片、文件、联网路由和桌面验收继续有效。

## 部署说明

- 本版本主要更新服务器配置加载和部署文档；员工客户端继续从公司服务器加载网页。
- 管理员填写本地 `config/deepseek.env` 后，通过受控方式复制到服务器私有路径，重启服务器即可；不要把填写后的文件上传 GitHub。
- Windows x64、macOS arm64/x64 安装包、公司服务器更新包和 SHA-256 校验文件由本版本 GitHub Release 提供。
- 当前发行包按项目签名政策标注签名状态；SignPath 尚未获批，不宣称已签名。
