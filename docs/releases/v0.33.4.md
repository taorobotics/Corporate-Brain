# v0.33.4 · 对话侧栏可拖动调宽

## 员工端更新

- “最近／项目”所在的对话历史侧栏支持拖动右边缘调整宽度，双击恢复默认。
- 调整后的宽度按账号保存在当前电脑，重新打开客户端仍然保留；窄窗口自动限制宽度，放大窗口后恢复个人偏好。
- 支持方向键微调、Home / End 调整至边界，Enter 恢复默认；也可在“视图”菜单点击加宽、缩窄或恢复默认。
- 拖动不会重建当前对话或清空输入草稿；按 Esc 或切离窗口可取消本次拖动。

## 客户端与服务器更新

管理员先备份并部署本版服务器更新包。员工重新打开连接该服务的客户端即可加载可调宽侧栏；仅更新桌面安装包不会替换服务器页面。桌面安装包及公司更新源同步为 0.33.4，沿用原公司地址和安装目录。

账号、部门、NAS、模型配置和密钥保留，不包含在公开更新包中。个人侧栏偏好保存在员工电脑。

## 验收与分发

原生桌面检查覆盖真实指针拖动、宽度边界、取消与复位、键盘与菜单操作、草稿保留、偏好保存与重新加载、窄窗口适配。正式 Release 提供 Windows x64、Mac arm64 / x64 DMG、服务器更新包、SHA-256 和各平台真实验收记录。

原创代码采用 MIT，第三方许可和隐私说明随包保留。Windows 尚未可信签名；Mac 仅 ad-hoc 签名、未公证。
