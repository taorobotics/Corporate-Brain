# v0.3.0

## 员工端更新

- 对话现在通过完整 DSH `sdk` profile 处理工具型请求，支持联网搜索与网页抓取（需配置 DeepSeek 搜索凭据）。
- 图片附件会作为视觉输入发送给支持视觉的对话模型，不再只显示“图片未发送”。
- 选定文本文件会放入按员工和会话隔离的临时工作区，DSH 文件工具可读取并分析内容。
- DSH 启动失败时保留原 OpenAI 兼容聊天回退，避免已有公司连接因运行时问题完全不可用。

## 管理与部署更新

- DSH 运行时、附件和工具工作区使用服务器私有目录；新增 `BRAIN_DSH_ENABLED`、`BRAIN_DSH_HOME`、`DEEPSEEK_API_KEY` 和 `DEEPSEEK_SEARCH_BASE_URL` 配置说明。
- 更新检查继续按三段数字版本比较，`0.2.9`、`0.2.10`、`0.3.0` 会按正确顺序识别；未配置或 GitHub 暂不可用时返回明确状态。
- 更新源状态、公开仓库模式和错误原因补充到服务与客户端提示中。

## 验证范围

- `npm run version:check`
- `npm test`（19 项通过）
- `npm run test:dsh`（隔离 DSH 初始化检查）
- `npm run build`
- `npm run test:desktop`（真实 Electron 窗口与桥接检查）
- `server/dsh.test.ts` 使用本机流式 OpenAI 兼容假服务验证 DSH 文本、图片和文件附件路由，不调用真实模型。

## 部署说明

- 客户端页面、业务服务和 DSH 路由一起随公司服务器更新包交付；升级前备份 `.data`，并为 DSH 临时目录配置私有可清理路径。
- Windows x64、macOS arm64/x64 安装包、公司服务器更新包和 SHA-256 校验文件由本版本 GitHub Release 提供。
- 当前发行包按项目签名政策标注签名状态；SignPath 尚未获批，不宣称已签名。
