# v0.34.11 · 统一 Noto Sans SC 字体

## 员工端更新

- 对话、登录、导航、设置、管理后台与启动动画统一优先使用 Noto Sans SC，中文、英文和数字保持同一套字体；代码仍使用等宽字体。
- 沿用第三期 CycleAI 的本地 Unicode 分片方案，按实际文字加载官方字体分片，支持 100–900 可变字重。
- 不依赖外部字体网站，首次连接和离线许可页面也带有相同字体。已加载分片长期缓存，减少后续重复下载。

## 客户端与服务器更新

客户端与服务器版本均为 0.34.11。Mac mini 更新服务器包后，员工重新打开页面即可使用新的在线字体；桌面首次连接及离线页面需安装新版客户端。Windows 沿用原目录后台更新，Mac 使用对应架构 DMG。公司更新源、安装包和服务包一并交付，部署前备份原数据、密钥和配置。

## 验证与许可

构建及安装包验收核对 101 份官方原始 WOFF2 的 SHA-256、字节数、许可和网页/桌面一致性。桌面检查确认实际渲染使用内置 Noto Sans SC，登录使用同一字体，并核对指纹文件的一年缓存和 304 复用。各原生平台及公司更新分发检查通过后正式发布。

原创代码采用 MIT，字体采用 SIL OFL 1.1，第三方许可继续保留。Windows 尚未取得可信代码签名；Mac 使用 ad-hoc 签名，未经过 Apple 公证。
