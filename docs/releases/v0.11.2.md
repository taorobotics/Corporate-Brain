# v0.11.2 · 左下角圆形更新按钮

## 员工端更新

- 更新入口移到左下角账号栏的最右侧，改为圆形向上箭头按钮。
- 有新版或安装包准备完成时显示蓝色按钮；下载时以外圈显示进度，悬停可查看当前状态与版本。
- 保留点击打开更新窗口、下载校验和确认安装流程；提供键盘焦点、按下反馈与减少动态效果适配。
- 账号名称和部门过长时自动省略，避免挤压底部按钮；设置和账号菜单继续可用。

## 下载与更新

Windows x64：`Corporate-Brain-Setup-0.11.2-x64.exe`；Mac：`Corporate-Brain-0.11.2-macOS-arm64.dmg` 和 `Corporate-Brain-0.11.2-macOS-x64.dmg`；公司服务器：`Corporate-Brain-Server-0.11.2.zip`。

本次主要为公司服务器提供的界面更新。管理员备份数据和配置后部署服务器包；员工重新打开客户端即可看到新的更新入口，原有受支持客户端仍可通过它下载新版。安装包沿用预配置公司地址，发布工作流完成后自动分发到公司更新服务。
