# v0.9.0 · 暖色启动动画与连接恢复

## 员工端更新

- 接入 DSH 技术档案风格的本地启动页：暖色底板、档案面板、旋转准星和揭幕过渡；随时跳过，保留窗口控制，支持系统减少动态效果。
- 设置 → 工作偏好 → 外观提供「默认（浅色）」「浅色」「深色」。默认始终为暖浅色；选择深色后下次启动也使用深色。可在设置预览启动动画。
- 修复旧客户端把整页超过 15 秒仍未加载完成判断为连接失败的问题。现在界面绘制完成即可进入，字体和图片可继续加载。
- 临时连接错误最多自动尝试三次；超时、DNS、断网、证书和服务器响应错误显示对应提示，保留手动重连。证书错误不会绕过安全校验。
- 普通界面数据读取增加 20 秒超时，避免初始化无限等待；提交类请求不自动重放。

## 下载与更新

- Windows x64：`Corporate-Brain-Setup-0.9.0-x64.exe`。
- Apple 芯片 Mac：`Corporate-Brain-0.9.0-macOS-arm64.dmg`。
- Intel Mac：`Corporate-Brain-0.9.0-macOS-x64.dmg`。
- 公司服务器：`Corporate-Brain-Server-0.9.0.zip`。

员工安装新版客户端才能获得本地启动页和自动重连。管理员需另行部署服务器包，设置里的主题选项和请求超时才会更新。现有登录账号、部门、公司密钥及员工本机对话保留，不要求清理客户端数据。新外观缓存只含主题名称，按公司地址隔离；账号内外观偏好仍保存于原有个人本机记录。

## 服务器更新

先停止服务并一致性备份 `.data`（包括 `secrets.key`）和服务配置，再解压到新版本目录；继续使用原数据库和密钥路径。保留原 HTTPS、端口和环境配置，安装锁定依赖后切换并检查 `/api/health`。服务器包包含预构建网页。发生问题时切回旧版本目录，不覆盖员工数据。

## 验证范围

- 本地及发布工作流执行后端、版本、TypeScript、生产构建和真实 Electron 交互检查。
- 启动专项覆盖：挂起的网络请求、图片未结束时进入界面、超时恢复、HTTP 503 自动重连、启动 IPC 来源边界、主题缓存与公司隔离、默认浅色、预览退出、减少动态效果、过期请求取消及关闭窗口清理。
- 工作流在 Windows x64、Mac arm64、Mac x64 原生环境构建并验证。Windows 安装、升级及卸载检查只在临时 CI 机器执行，不覆盖用户电脑上的客户端。
- 每个平台的真实检查记录和 SHA-256 随 Release 提供；未声称已在员工实体 Mac 上安装测试。
