# v0.25.0 · 供应商模型菜单与米白对话

## 员工端更新

- 对话中的模型选择按供应商收拢。鼠标悬停或点击 LinoRoute，右侧展开模型列表；支持键盘方向键、选中标记、长列表滚动，以及窄窗口自动避让。
- 保留每个连接的独立标识与权限。个人和公司授权模型可在同一供应商下选择，标明来源；员工仍只能使用本人配置或公司授权的连接，图片模型继续作为技能。
- 默认 Claude 浅色皮肤保留米白背景，回复与客户端统一使用现有无衬线字体。正文根据窗口采用 18px、17px 或 16px，改善标题、段落、列表和表格的留白；调整用户气泡、输入框与导航尺寸。
- 修复内容折叠、窗口变化导致浏览器调整滚动位置时，偶尔错误暂停自动跟随的问题；主动上翻阅读仍会暂停。

## 管理员与服务器更新

界面与模型请求由服务器包交付，无数据库结构变更。更新前停止服务并一致性备份数据库、`secrets.key` 和配置，在新目录解压服务器包、安装锁定依赖，沿用原数据目录及 HTTPS 设置启动。连接该服务器的现有客户端重新打开即可加载新版网页；Windows 安装包可通过“安装”后台升级，Mac 使用对应架构 DMG 替换。

新增可选服务端配置 `BRAIN_MODEL_DOH_HOSTS`，只为明确指定的模型域名使用经过 HTTPS 校验的公共 DNS 解析，保留原域名、SNI 和证书校验，拒绝私网解析结果。适用于公司网络把公网模型域名解析到错误地址的情况，不修改系统 DNS、其他项目或 NAS 解析；默认不开启。普通对话、目录读取、图片、制作及 DSH 代理使用同一模型传输边界。详见 DEPLOYMENT.md。

## 检查与边界

隔离原生验收覆盖供应商归组、真实鼠标悬停右侧展开、30 项列表滚动、点击/键盘选择、重载保持与窄窗口避让，同时保留原有滚动、处理过程、表格、代码、个人模型隔离和成果保存检查。DNS 测试覆盖限定域名、TTL 缓存、未配置域名保持原解析和私网结果拒绝。各平台真实构建、安装与校验记录随 Release 分发。

本次另在 Mac mini 使用已有 LinoRoute 配置，对目录返回的 8 个 Opus 型号各进行一次最小文本请求，7 个返回 HTTP 200 和预期内容；`claude-opus-4-20250514` 返回 503，不加入本次默认可选项。调用成功只代表该时刻中转服务可用，不构成原厂模型身份或后续服务可用性的保证。公司模型列表部署时只追加验证通过的型号，不包含真实密钥。

v0.24.1 候选草稿未公开发布，其米白排版更新随本版统一交付；旧标签不覆盖。源码和安装包不含数据库、员工聊天、密钥或内部技能。原创代码采用 MIT，第三方保留原许可；隐私及签名政策随包分发。Windows 未获可信签名，Mac 为 ad-hoc 签名且未做 Apple 公证。使用 `SHA256SUMS.txt` 校验下载文件。
