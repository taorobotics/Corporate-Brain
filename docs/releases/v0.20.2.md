# v0.20.2 简化对话输入框

## 员工端更新

- 移除对话输入框底部的 Token 数字、“估算 / 本轮”及“额度待配置”显示，模型选择与工作区权限直接相邻，释放输入框底部空间。
- 保留发送、附件、技能、多模型选择、工作区权限与已有用量记录；本次不改变模型请求或额度规则。

## 客户端与服务器更新

本次为服务器网页界面更新。管理员一致性备份后更新 Mac mini 的代码与网页，保留原数据库、模型密钥、NAS、技能及 HTTPS 配置；连接该服务器的客户端退出后重新打开即可使用。新版安装包递增为 0.20.2，继续使用已有更新入口。

Windows 更新沿用原目录后台安装并自动重启；Mac 使用对应架构 DMG。局域网安装包默认连接 Mac mini，正式 GitHub 包使用发布配置的公司地址，已有客户端继续保留自己选择的服务器地址。

## 验证范围

运行类型检查、生产构建及既有桌面交互验收，核对浅色、深色和窄窗口的输入框、模型及权限选择。正式 Release 需 Windows x64、Mac arm64、Mac x64 和服务器四个构建及安装、更新分发检查全部通过后公开；最终检查和部署记录另行填写。
