# v0.16.0 · 个人资料与 100 个 IPAS 头像

## 员工端更新

- 在“个人设置 → 编辑个人资料”修改显示名称、选择头像或上传自己的图片；左下角、账号菜单、聊天头像及管理后台同步显示。
- 内置从 IPAS 网站随机选取的 100 个不同角色，支持中文/英文搜索和随机换一个。默认头像随账号保持稳定，新账号自动分配，旧账号也可直接使用。
- 自定义头像支持 PNG、JPG、WebP，上传后可调整大小和位置；保存前可取消。资料随账号保存，其他设备下次登录时读取。
- 默认头像保存在公司服务器，客户端不依赖外部素材网站，不包含该网站的统计代码。

## 服务器与客户端更新

此版本需要更新公司服务中的网页、服务代码及依赖，新增 users.avatar 字段。升级前备份公司数据库和配置；不覆盖账号、密码、部门、NAS、模型密钥或员工本地记录。用户上传头像作为公司数据保存，不随发行包分发。

客户端从公司服务加载界面，服务器更新后，已有客户端重新打开即可使用资料编辑。新版安装包包含更新后的隐私及第三方来源说明；客户端安装与服务器升级分别进行。

IPAS 来源、逐图摘要及授权声明保存在 docs/assets/ipas-avatar-sources.json 与第三方声明中。默认头像使用网站提供的原样 512px WebP 文件。没有生成或引入“小黄人”电影角色素材。
