# v0.11.6 · 修复识图与长任务被三分钟时限中断

## 员工端更新

- 修复图片识别等多步骤任务在仍有思考或工具进展时，被固定 180 秒总时限强制中断的问题。
- 改为按真实进展判断超时：思考文字、回答文字、工具活动会刷新等待时间；连续 180 秒无新进展时结束请求。连接心跳和空内容不算模型进展，单次任务仍有 15 分钟总上限。
- 区分主动停止、长时间无响应和达到总处理时限，保留已经接收的文字与过程，给出对应提示；普通 JSON 调用超时返回 504。
- 清理完成或取消请求的计时器，启动 DSH 期间也能及时取消；不同对话的请求互不取消。
- 图片请求优先分析可见内容，仅在必要时旋转或裁剪；对模糊、截断内容明确说明，减少反复处理和猜测，保留用户明确要求的工具操作。
- 保留 0.11.5 的对话自动跟随、上翻暂停和“回到最新内容”。

## 下载与更新

Windows x64：`Corporate-Brain-Setup-0.11.6-x64.exe`；Mac：`Corporate-Brain-0.11.6-macOS-arm64.dmg` 和 `Corporate-Brain-0.11.6-macOS-x64.dmg`；公司服务器：`Corporate-Brain-Server-0.11.6.zip`。

本次核心修复在服务器。管理员先备份，再部署服务器更新包；员工之后发起的新请求即可使用修复。已经结束的失败请求不会自动续跑，需要重新发送。客户端安装包通过左下角更新入口另行安装；只安装客户端不能替换旧服务器程序。独立部署的 Mac mini 需单独更新服务器。

## 验证与分发

新增可控时间的超时测试与真实 HTTP 流测试，覆盖持续进展超过旧时限、空事件不能延长等待、无响应错误、总时限、取消隔离和完成后清理。DSH 原有真实子进程、图片传递、取消和重新请求检查继续执行；桌面滚动验收使用真实鼠标导航并等待布局稳定，避免测试步骤之间的时序竞争。

针对实际失败图片，使用相同模型在隔离工作区进行真实识别验证；报告仅记录时长、计数和完成状态，不发布原图、回答、思考内容或员工记录。最终生产验证另行记录，测试通过不代表模型能准确识别所有模糊或复杂图片。
