# v0.4.0

## DSH 工作区与模式

- 员工端新增可命名的本地工作区，可在工作区菜单中切换或添加工作区。
- 新增标准模式、PTC 模式、极简模式和创造模式，分别映射到 DeepSeek Harness 的对应 Agent preset。
- 新增仅可查看、工作区内修改和完全权限三档工作区权限，映射到 DSH 的 read-only、workspace-write 和 danger-full-access 沙箱策略。
- 工作区和模式设置按员工账号保存在本机；旧版本的问答、规划和执行设置会迁移到标准模式。

## Token 与额度显示

- 对话输入区显示本轮 Token 使用量；发送前显示文本和附件的估算值，服务返回用量后显示实际值。
- 当前公司连接尚未配置额度上限时，客户端明确显示“额度待配置”，不会伪造剩余额度。

## 兼容与安全

- DeepSeek Flash/Pro、联网搜索、图片输入和文本附件能力继续由公司服务器提供，API Key 仍只保存在服务器。
- 客户端工作区路径仅保存在员工本机；服务端 DSH 会话仍按员工和会话隔离。
- 服务器端保留旧数据库和密钥格式，不需要迁移已有账号、部门或模型连接。

## 验证

- `npm test`：27 项通过。
- `npm run build`：通过。
- `npm run test:desktop`：Electron 实窗口、工作区菜单、四种 DSH 模式和三档权限选择通过。
- 本地 Windows x64 安装包使用公司服务器地址预配置，不包含 API Key。

## 部署

- 公司服务器更新到 `v0.4.0` 后，员工重新打开或刷新客户端即可获得新界面。
- 本次直接部署到公司服务器，不同步 GitHub Release；如后续公开发布，需按项目发布策略补齐各平台包、校验文件和签名状态。
