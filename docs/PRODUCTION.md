# 对话工作流与本机成果

从 0.19.0 起，员工直接在 AI 对话中提交代码或视频需求，侧栏不再提供单独的制作中心。AI 自动识别需求，使用后台已授权的对话模型制定实际执行计划，再编写代码；视频由公司 Mac mini 的隔离 Chromium Canvas 渲染器和独立 FFmpeg 进程生成 MP4。没有启用 Remotion。规划和代码生成使用公司现有模型额度。

## 员工使用

安装 0.17.0 或更新客户端，在对话输入要求、按需添加原始素材并发送。首次制作会提示选择本机文件夹，也可在“设置 → 工作偏好 → 成果自动保存位置”更换。0.19.0 新客户端增加本机成片与源文件预览；旧客户端可正常执行任务、显示步骤、重试、保存和打开成果文件夹。视频目前为 720p、24 fps、1–60 秒；图片和视频可作为画面素材，首个 MP3/WAV/M4A/OGG 可作为配乐，其他文件原样交付。文本素材供模型参考；未供应的配乐、人声和实拍素材不会凭空生成。

对话内展示五步实际执行状态：制定执行计划、生成代码、渲染/检查源码、校验成果、保存到本机并清理服务器。计划由模型返回并保存，步骤由真实后台操作驱动，任务刚提交时不显示完成。代码格式、语法或渲染出错时最多自动修复一次，仍失败则展示失败环节并提供“在此重试”和“停止任务”。刷新或重新登录后仍可查看后台状态。“我的作品”保留历史任务和成果入口，不再提供另一个提交表单。

每项任务保存到独立文件夹：`code/` 为源代码，`materials/` 为原始素材，`output/video.mp4` 为成片，`request.txt` 为制作要求，`plan.md` 为执行计划。对话内可展开文件列表；新客户端支持预览不超过 64 MB 的已保存 MP4 和不超过 512 KB 的源码文本。预览只读取当前账号本机回执中允许的文件，校验 SHA-256；不执行 HTML、脚本或生成的项目。较大或已编辑文件使用“打开成果文件夹”查看。

Mac mini 每次制作一项任务，其余排队。每人最多保留 3 个未完成回传的任务，全平台最多 64 个。每项最多 8 个素材、每个 128 MB、合计 512 MB；代码输出最多 32 个文件、4 MB。视频渲染最多 15 分钟，渲染器内存达到约 1.5 GB 时停止该任务。

## 回传和清理

任务绑定员工账号和提交设备。客户端前台打开期间每 2 秒检查，切换页面仍继续接收。断网或关闭客户端不取消服务器任务，下一次打开、登录同一账号后继续接收。另一台电脑不会抢先保存并删除这台电脑的任务。

下载采用流式写入，完成一个文件后校验长度及 SHA-256，再发布为正式文件。重试跳过已验证的文件；不会覆盖员工改动过的成果。原生目录选择构成写入授权，导入聊天记录不能授权另一个写入位置。拒绝路径穿越、保留设备名和目录链接。

所有素材、代码和成片落盘、再次校验并持久化保存回执后，客户端才发完整保存确认。服务器核对员工、设备和清单后立即清理该任务目录，同时清除数据库中的要求与清单内容，只留下少量任务状态。确认响应丢失时可用本机回执幂等重试。服务器清理失败时显示“本机已保存，正在清理服务器”，不会删除本机文件。

关闭客户端时仍未回传的成果及失败任务会继续占用服务器磁盘，不设置七天自动删除。员工可以重试或明确取消并清理。进程结束释放渲染内存；成功回传或取消后清理任务磁盘。SQLite 与管理员备份有独立生命周期，本功能不是对已有备份的安全擦除。

## 服务器部署

在服务器包目录运行 `npm ci --include=dev`，Electron 与 ffmpeg-static 安装器将为当前系统获取运行组件。服务器包与员工安装包均不含 FFmpeg 二进制。Mac mini 需有登录中的图形用户会话（本项目既有 LaunchAgent 环境）；Linux 需要管理员另行提供合适的图形环境。本次真实渲染验收为 Mac arm64，不承诺已验证所有服务器平台。

- `BRAIN_PRODUCTION_ROOT`：可选，默认数据库所在目录的 `production`。
- `BRAIN_RENDER_ELECTRON`：可选，已安装 Electron 可执行文件绝对路径。
- `BRAIN_RENDER_FFMPEG`：可选，经管理员核对许可的 FFmpeg 可执行文件绝对路径。

源代码在 `sandbox: true`、无 Node、无 preload、无员工 cookie 的专用渲染器内的 OffscreenCanvas Worker 执行（无 DOM、窗口或 WebRTC 接口）。仅映射该任务枚举的媒体文件，禁外网、本机文件 URL、导航、弹窗和权限请求。子进程只得到必要系统变量，模型密钥、NAS 凭据不传入。任意生成的 Node、shell、安装命令不会由制作中心执行。渲染停止会结束编码进程，服务器退出也会终止当前渲染。

请保留 [Canvas / FFmpeg 许可说明](../src/vendor/canvas-rendering.NOTICE)。上游 arm64 FFmpeg 带 `--enable-nonfree`，仅在内部服务器安装使用，不得打入对外分发包。Remotion 仅保留适配器接口；取得公司授权前不启用。

## 检查

`npm test` 包括账号/设备隔离、清单匹配、取消、重启、断线续传、回执恢复、路径穿越和本机文件保护。`npm run test:production` 检查真实客户端操作及原生保存；在 Mac 运行 `npm run test:render` 生成带音频的实际 MP4，逐帧解码确认 72 帧并检查隔离边界。线上验收使用合成任务，不使用员工资料。
