# 账号与个人资料

入口：员工端左下角账号菜单 → 个人设置 → 编辑个人资料。

- 可修改显示名称；登录账号、部门及角色不能由此修改。
- 内置 100 个从 IPAS 网站随机选取的不同角色，支持中文/原始英文名称搜索、随机选择和重新裁剪。
- 新账号按随机账号标识分配一个稳定的默认头像。旧账号也获得稳定默认头像；保存后不会在每次登录时重新随机。
- 支持上传 PNG、JPG、WebP，客户端限制 10MB，允许放大和调整位置。裁剪后发送小图；公司服务器验证并重新编码为 256px WebP，去除元数据。
- 显示名称和头像保存至公司服务的账号记录，同账号其他设备重新登录时读取最新资料。完整聊天仍只保存在用户本机。
- 上传图片不会成为公开静态文件，仅通过获准的账号资料接口返回；管理员在原有账号管理范围内可查看账号资料。

默认头像位于 `public/avatars/ipas-v1/`，构建后进入 `dist/avatars/ipas-v1/`。运行时无需连接 IPAS 网站。来源、随机选择种子、原始名称及摘要见 `docs/assets/ipas-avatar-sources.json`；授权声明见 `src/vendor/ipas-avatars.NOTICE`。

服务器升级会为 users 增加 avatar 字段，保留账号、密码、权限及原有数据。头像变更审计只记操作者、动作与账号 ID，不记图像内容。用户自定义头像跟随公司数据库备份，不进入源码或发行包。

## 修改登录账号与密码

个人设置 → 修改登录账号：使用全公司唯一的 2–64 位字母、数字或 `. _ @ -`，验证当前密码后保存。当前设备保持登录，其他设备需重新登录。内部账号 ID、部门、角色、头像和按 ID 保存的本机对话保留。修改显示名称仍使用“编辑个人资料”，不会自动修改登录账号。

个人设置 → 修改密码：至少 12 位，修改后所有设备退出，使用新密码重新登录。部门与角色仍由获准管理员分配。

## 按部门开通与查看密码

公司管理员进入管理后台 → 部门与员工账号 → 随机开通账号，选择业务部门并输入每部门人数（1–20，默认 20），验证管理员密码后生成随机登录账号、名称和密码。初始密码 30 天内有效，首次登录须改密；逐人添加、导入与重置密码仍为 24 小时。同一批次请求重试不会重复创建；生成过程中管理员权限、登录或部门状态发生变化会拒绝写入。

公司管理员可在员工表格“当前密码”列逐个查看非公司管理员账号密码。每次须验证自己的当前密码，展示 30 秒或切到后台后隐藏，并记录查看者、目标账号和时间。员工改密后，后台展示最新密码。员工、部门管理员和审核员没有查看权限；普通账号清单导出不含密码。公司管理员自身密码仅在开通或重置结果中显示一次。

登录仍通过不可逆密码摘要校验，可查看的密码另存为 AES-256-GCM 密文，沿用部署的 `secrets.key`。数据库与密钥必须配套备份。既有旧密码不能从摘要还原，下次改密或重置后才可查看。员工改密页明确告知该管理机制；详见 PRIVACY.md。
