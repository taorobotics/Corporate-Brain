# 公司大脑 UI 基准

日期：2026-10-16。用途：将已选定的视觉方案与开发页面对应。图片是效果图，不是可运行程序或真实业务数据。

## 1 统一规则

1. 桌面主界面采用 Claude Code 与 Codex 混合工作台风格：暖白与浅灰、深灰文字、细线、轻阴影和克制的陶土色强调。
2. Windows 顶部包含后退、前进、侧栏开关、文件、编辑、视图、帮助和窗口控制；macOS 使用适合系统习惯的菜单与窗口行为。
3. 对话默认右侧预览收起，成果可在对话内展示；点击成果时展开右侧，支持调宽、缩放、适应窗口、全屏和关闭。
4. 最右侧预览属于员工对话。项目、公司知识、技能中心、作品和设置使用完整主内容区；详情进入页内，不打开常驻右侧详情面板。
5. 左下角头像和姓名整行可点击，小菜单向上弹出，点击外部或 Esc 关闭。设置齿轮可以保留为快捷入口。
6. 临时 Logo、公司名称、主题色和图标资源集中管理，后续统一替换。
7. 员工网页端共用主要视觉和操作；系统窗口控制由浏览器提供，本地文件能力以已连接的本地助手为条件。
8. 管理后台是网站：使用自己的网页顶栏与管理导航，延续色彩和控件体系，不照搬桌面原生菜单。
9. 功能可见、可用、加载、失败、未配置、离线和无权状态须实际设计。效果图里的按钮不应在开发后只保留外观。
10. 侧栏最近对话与个人草稿只列当前设备、公司和账号的本地数据；切换账号或换设备不从服务器加载历史。共享项目不展示其他员工的完整对话。
11. 设置增加本地记录、保存位置、导出导入与备份说明。网页端说明浏览器本地保存及清除数据的影响。状态文案使用记录已保存到本机、设置已保存或公司配置已更新，不用已同步暗示聊天云同步。
12. 从对话创建 Skill 时，先选择用于提炼的本地记录，再预览发布包文件、可选示例摘录和测试摘要；两次选择的用途须分别说明。提交前明确展示发布范围，未提交草稿显示仅保存在本机。
13. 后台审核中的查看来源只打开作者提交的摘录，不提供浏览员工本地聊天的入口。原效果图里的同步、来源与试运行文案均须按此边界实现；归档图保留原样。
14. 账号菜单与个人资料显示所属部门，只读；本地历史仍按公司和员工账号隔离。技能中心区分本部门、跨部门共享、全公司、我创建的和已安装，列表及详情显示归属部门与发布范围，只列当前账号获准内容。
15. 后台部门与员工账号页采用部门列表加完整主内容区，支持按部门查看成员、建部门、单个或批量开通账号、导入预览与逐行错误、初始密码取用及分发状态、重置和调部门。现用密码不展示，初始临时密码取用与普通账号导出分开；本部门管理员只见自己获准的管理范围。
16. Skill 提交默认本部门，其他范围为指定多个部门或全公司，提交页明确显示归属部门和所需审核。审核页按部门、发布范围与状态筛选，部门审核员不能通过按钮扩大到公司发布权；推荐分发页只能选择已获准受众，客户端显示待确认安装通知。
17. 字体按用户指定的 [Marvis 官网](https://marvis.qq.com/) 调整：中文界面优先本机苹方 PingFang SC，后备使用随产品提供的 Noto Sans SC 可变字体，再回退系统字体。网页、员工客户端、后台和原生公司连接页共用该顺序。Noto 字体由公司服务器或客户端自身加载，保留 OFL；字体来源及实际渲染记录见 [FONT-SPEC.md](FONT-SPEC.md)。腾讯的 Gilroy 品牌字不用于公司临时 Logo。
18. 客户端普通窗口的四个外角采用系统原生小圆角及系统阴影。Windows 工作区使用 8px 圆角的细边线与原生轮廓衔接；最大化与全屏时移除边线并改为直角贴边，还原窗口时恢复。macOS 保留系统原生边框。网页内部不仿造操作系统窗口边框。Windows 11 以下的原生外角受操作系统能力限制；不为圆角引入透明窗口或修改窗口形状，以保留系统缩放与窗口操作。
19. 员工端、管理后台、设置和技能编辑共用下拉控件：沿用 Marvis 字体、暖白表面、陶土色选中底色、细边和轻阴影，选中项同时显示勾选。对话输入区使用紧凑触发按钮并优先向上展开；表单使用完整宽度按钮。浮层放入 Portal，按窗口边缘调整位置，长列表独立滚动；顶部命令和账号菜单遵循同一视觉体系。支持键盘导航、Esc、点击外部关闭、焦点恢复和减少动态效果偏好。弹窗里的第一次 Esc 关闭下拉层，下一次才关闭弹窗。
20. 模型列表只列当前任务类型下已启用的获准连接；长名称省略时可查看完整标题。没有模型时展示原因和真实“模型与服务”入口，不伪造模型选项；尚未接通的视频、规划和执行能力在选项中标记“接入中”。

## 3 已约定但需要继续细化的状态

这些状态属于 PRD 范围，不能因为尚无独立效果图而省略。

- 登录、首次公司服务连接、错误密码、账号停用、会话过期。
- 部门建立编辑启停、按部门批量开通账号、导入校验、初始密码取用与分发状态、首次改密、重置和调部门。
- 新建任务空状态、正在执行、停止和失败恢复。
- 项目创建、成员设置、项目内部任务文件技能列表。
- 知识阅读、搜索无结果、NAS 离线、无权和解析失败。
- Skill 草稿提炼、参数编辑、试运行、提交、退回、更新、回退和依赖缺失。
- 本地记录导出导入、重复记录处理、附件失效、换设备空历史和账号切换后的隔离。
- Skill 提炼输入预览、实际发布文件清单、可选摘录选择、仅本机草稿和审核来源摘录。
- Skill 默认本部门提交、跨部门或全公司发布申请、按范围审核、部门推荐分发与确认安装、调部门后安装项失权及归属移交。
- 图片多轮编辑、视频排队与状态恢复、保存失败和待归档。
- 文件与权限设置、网页端本地助手配对和断开。
- 模型连接测试成功与失败、模型列表不可用时手动填写、公司策略禁用个人连接。
- 管理后台公司知识、用量、客户端发布和系统设置。
- 登录与表单的键盘导航、错误提示、空数据和窄窗口布局。

## 4 视觉验收办法

开发时以同一窗口尺寸、同一页面和同一交互状态比较程序截图与基准图，记录导航、比例、文字、表单、菜单和预览差异。不能用程序能启动代替视觉验收。

界面截图不得出现真实密钥。示例人数、剩余额度、连接成功和试运行通过标记只在演示环境使用；真实环境从后端结果展示。

## 5 开发版对照记录

Windows 安装器按用户确认的[四步向导图](design/approved/windows-installer-wizard.png)实现，采用原生控件、暖白与陶土色。包含欢迎、安装位置、真实进度与旋转加载项、完成；D 盘优先仅适用于新装，覆盖升级锁定原路径。完成页分别提供立即打开与完成，卸载明确保留个人记录。运行规则与验证范围见 [Windows 安装向导](WINDOWS-INSTALLER.md)。Mac 仍用原拖拽安装界面。

v0.1 的实际窗口截图位于 artifacts/screenshots；已实现页面的视觉核对见 [design-qa.md](../design-qa.md)。部门管理、初始账号分发、本地记录与技能主动提交的交互按第 1 节新增规则实现。未实现的完整模块不因本次视觉核对通过而自动视为已开发。
