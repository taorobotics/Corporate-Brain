# 对话附件

从 0.15.0 起，对话输入框的“添加文件”使用客户端内置文件选择界面，支持多选、拖放、粘贴图片、读取进度、取消与预览。旧安装包从更新后的公司服务加载界面，也可使用这些能力。

| 格式 | 读取范围 | 单文件限制 |
| --- | --- | --- |
| DOC / DOCX | 正文与表格文字；不运行宏，不读取外部链接 | 10MB |
| XLSX | 最多 30 张工作表、20000 个单元格的已保存值；不计算公式，日期可能保留原值 | 10MB |
| PPTX | 最多 100 张幻灯片的文字；保留演示文稿顺序 | 10MB |
| PDF | 前 80 页文字；前两页及后续扫描页合计最多 8 页画面；加密文件先解密 | 25MB |
| TXT / MD / CSV / JSON / LOG / SRT / VTT | UTF-8、UTF-16 或 GB18030 文本 | 5MB |
| PNG / JPEG / WebP / GIF | 单张图片；GIF 第一帧；缩小后用于分析 | 20MB |
| MP4 / MOV / WebM / M4V | 最多 8 张等间隔抽样画面，带时间点；需运行环境支持其编码 | 200MB、10 分钟 |

每次最多 8 个附件、总计 16 张画面；每份文档最多提取 120000 字符。超过读取范围会显示说明并一并传给模型，不假装全文已读。旧 XLS / PPT 需另存为 XLSX / PPTX。Office 中的内嵌图片、批注和完整排版不在文字提取范围；需要分析图片时另存 PDF 或单独添加图片。

视频当前只分析抽样画面，不读取音轨、不转录声音，也不是原生整段视频输入。可另加 SRT / VTT 字幕；短暂动作可能落在采样之间。视频分析在“对话”中添加附件；“视频”任务选项仍是尚未接通的视频生成入口。

## 模型与隐私

DeepSeek 官方 `deepseek-flash` 支持图像，`deepseek-v4-pro` 不处理图像。含图片、PDF 页面或视频画面的请求需要选择 Flash；其他兼容服务是否支持视觉取决于实际模型。实现使用标准图片内容块，保留来源页码和采样时间。参考：[Vision](https://api-docs.deepseek.com/guides/vision/)、[Anthropic compatibility](https://api-docs.deepseek.com/guides/anthropic_api/)。

PDF、图片、视频在员工客户端处理。Office 文档通过已登录的公司服务临时解析，原文件不写入数据库或磁盘，也不提供任意路径读取。点击发送后，提取文字与画面通过公司服务交给所选模型；本地历史保存提取结果，不保存原始视频。随后无新附件的追问会带上最近一次附件，重新分析仍可能计费。

解析器只接受固定类型和大小，Office 解析在独立进程中限时 20 秒、限定堆内存；禁止 XML DTD 和外部关系访问，限制 ZIP 展开量和目录路径。每位员工最多一个 Office 解析、公司服务最多两个并发。返回结果前复核会话有效性；日志不记录原文件或正文。附件文字作为资料处理，不能提高模型、员工或工具权限。

PDF.js、字符映射及标准字体随服务器包发布，不依赖外部 CDN。`npm run build` 生成这些资源。附件界面测试使用 `npm run test:attachments`，夹具均为合成资料，无生产数据或模型调用。
