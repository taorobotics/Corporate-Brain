# 公司大脑隐私说明 / Privacy policy

更新日期：2026-10-19。适用于本仓库发布的开源公司大脑客户端、员工网页和公司服务。实际公司部署的运营者是提供公司服务器地址的组织，员工可向本公司管理员咨询数据访问、保留与删除事宜。

## 本机保存

完整对话、个人项目、个人 Skill 草稿和使用记录保存在当前员工电脑或当前浏览器，按公司入口和员工账号隔离。它们不会自动上传公司服务器、NAS、GitHub 或项目维护者。更换电脑不会自动同步；导出备份文件包含所选本地内容，应由本人妥善保存。清除浏览器数据、删除应用数据目录或遗失设备可能丢失记录。

## 公司服务接收什么

连接与登录会把账号和密码通过所填公司入口发送至该公司服务；正式远程入口只接受 HTTPS。公司服务保存部门、账号密码哈希、权限、登录会话、员工主动提交的 Skill 包、审核记录、配置的模型连接及必要操作元数据。管理员不能通过本产品读取员工未提交的完整本地聊天或个人草稿。

员工提交 Skill 前可预览拟上传的流程、示例摘录、测试摘要和共享范围。提交会将这些选定内容发送至公司服务。管理员与获准审核者可按部门和角色查看、审核和分发；公司内部 Skills 属于部署数据，不自动进入本项目公开源码或发行包。

## 模型调用与文件

只有发起任务、试运行或明确测试连接时，才会将本次必要的提示词、选定上下文和附件发送至公司配置的服务与模型供应商。这可能包含员工选中的公司资料。公司管理员负责说明实际供应商及其数据政策、配置授权与保留期限；不应把密钥或与任务无关的敏感内容放进提示词。

选择文件只读取界面明确支持、由用户选中的文件。保存、导出或下载使用用户指定位置或应用数据目录。当前视频、NAS 检索和完整 Agent 文件执行尚未完成，不能把入口或设置当作已启用的能力。

## 更新与外部网络

连接公司入口会向该服务发送必要的网络请求。启用更新后，客户端登录时和运行期间通过公司服务检查 GitHub Releases，主动下载时由公司服务代理取得对应安装包。GitHub 可看到公司服务器的出口 IP、请求时间及标准请求元数据；公司 GitHub 读取令牌只保存在服务器，未分发给员工或写进安装包。直接访问公开仓库和下载页时，GitHub 按自己的政策处理访问数据。

应用代码没有接入广告、产品行为统计或远程崩溃上传服务，不向项目维护者集中上传聊天。Electron、操作系统以及管理员选定的第三方供应商可能有各自的联网行为和政策。当前不存在未经说明的后台训练、把员工聊天自动制作成公共 Skill 或自动公开公司数据的机制。

This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it. The configured company service, selected model providers, and enabled GitHub release checks described above are the network destinations requested by the user or operator.

## 管理、删除与反馈

员工可导出本地记录；删除本机应用数据前应先备份。公司数据、已提交 Skills、账号及模型配置的访问和保留由公司管理员按实际组织制度管理。用户反馈应先移除真实公司名称、密码、令牌、内部文件和聊天；敏感安全问题按 SECURITY.md 私下报告，不在公开 Issue 上传原始公司数据。

- 模型供应商：以公司管理员实际配置和告知的服务政策为准；本项目不替未指定供应商作保留或训练承诺。
- 组件许可见 THIRD_PARTY_NOTICES.txt；开源许可不替代任何供应商的服务条款。
