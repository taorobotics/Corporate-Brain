# 公司大脑隐私说明 / Privacy policy

更新日期：2026-11-04。适用于本仓库发布的开源公司大脑客户端、员工网页和公司服务。实际公司部署的运营者是提供公司服务器地址的组织，员工可向本公司管理员咨询数据访问、保留与删除事宜。

## 本机保存

完整对话、个人项目、个人 Skill 草稿和使用记录保存在当前员工电脑或当前浏览器，按公司入口和员工账号隔离。它们不会自动上传公司服务器、NAS、GitHub 或项目维护者。更换电脑不会自动同步；导出备份文件包含所选本地内容，应由本人妥善保存。清除浏览器数据、删除应用数据目录或遗失设备可能丢失记录。

## 公司服务接收什么

连接与登录会把账号和密码通过所填公司入口发送至该公司服务；正式远程入口只接受 HTTPS。公司服务保存部门、账号密码哈希、权限、登录会话、员工主动提交的 Skill 包、审核记录、配置的模型连接及必要操作元数据。管理员不能通过本产品读取员工未提交的完整本地聊天或个人草稿。

员工提交 Skill 前可预览拟上传的流程、示例摘录、测试摘要和共享范围。提交会将这些选定内容发送至公司服务。管理员与获准审核者可按部门和角色查看、审核和分发；公司内部 Skills 属于部署数据，不自动进入本项目公开源码或发行包。

## 公司管理的账号与密码

公司管理员可按部门批量开通随机员工账号。员工在个人设置中可修改显示名称、登录账号与密码，账号的固定内部标识和所属部门不会因此改变。修改登录账号须验证当前密码；当前设备继续登录，其他设备的登录失效。修改密码使全部已有登录失效。

从 v0.21.0 起，新建、重置或员工主动修改的非公司管理员密码，除登录校验用的不可逆摘要外，还以 AES-256-GCM 加密形式保存在公司数据库。仅公司管理员验证自己的当前密码后可逐个查看，操作记录保存查看者、目标账号和时间，不记录密码；页面 30 秒后自动隐藏。员工和部门管理员不能通过该入口查看任何人的密码，公司管理员的密码不保存可供查看的副本。请使用专属工作密码。旧账号既有密码摘要不能还原，只有下次改密或重置后才有可查看的记录。

账号表格和普通清单导出均不包含明文密码。密码记录和加密密钥属于内部部署数据，不进入公开仓库、安装包或检查报告；公司历史备份可能包含先前的加密记录，须与密钥配套保管。

## 个人头像与名称

员工可主动修改显示名称、选择内置头像或上传自定义头像。资料保存在公司服务器并随账号使用，其他设备重新登录可读取。上传图像在客户端裁剪后由服务器验证、缩小并去除元数据；服务器只保留处理后的头像。管理员在现有账号管理权限范围内可查看资料，修改审计不记录图像内容。更换头像会替换当前图像，历史公司备份可能按组织保留策略继续保存旧资料。用户上传的头像不会进入公开源码或安装包。内置 IPAS 头像随公司服务分发，员工客户端不直接连接素材网站。

## 回答评价与分享

员工主动点赞或提交回答反馈时，公司服务保存提交人、部门、模型名称、评价、问题类型、说明和处理记录；只有公司管理员可查看反馈表格与详情。反馈默认不附对话。勾选并预览“附上当前问题与回答”后，才保存该次所选文本（问题最多 20,000 字符，回答最多 50,000 字符），不上传其他轮对话、思考过程或附件文件；所选正文可能包含引用的资料。重新提交不勾选时会移除之前的文本摘录。反馈随公司数据库备份，由部署组织管理保留和删除，不进入公开仓库或安装包。

复制与分享回答仅写入本机剪贴板或用户选择的文件，不创建公开访问链接。转发前应检查内容与收件人。

## 模型调用与文件

只有发起任务、试运行或明确测试连接时，才会将本次必要的提示词、选定上下文和附件发送至公司配置的服务与模型供应商。这可能包含员工选中的公司资料。公司管理员负责说明实际供应商及其数据政策、配置授权与保留期限；不应把密钥或与任务无关的敏感内容放进提示词。

选择文件只读取界面明确支持、由用户选中的文件。Word、XLSX、PPTX 在选择后发送至已登录的公司服务器临时解析，原文件只在内存和受限子进程中处理，不写入数据库或磁盘；PDF、图片和视频画面在员工客户端处理。点击发送后，提取文字和画面才交给所选模型。视频仅抽样画面，不读取音轨；附件结果保存在本地历史，后续无新附件的追问会复用最近附件。

聊天路由会把画面作为视觉输入，把提取的文档文字放入按员工和会话隔离的 DSH 临时工作区供文件工具读取；DSH 工作区不等于员工整盘授权。解析过程不运行 Office 宏、不访问外部文档链接。保存、导出或下载使用用户指定位置或应用数据目录。

公司知识通过公司服务器按当前员工部门连接获准的 NAS 目录，仅显示名称、类型、大小和修改时间。NAS 密码以加密形式保存在公司服务，员工客户端不接收密码。目录内容不持久缓存，审计仅记录资料源和操作，不记录文件名。当前不读取 NAS 文件内容、不向 AI 发送 NAS 内容，也不提供下载、写入或自动备份聊天。NAS 全文检索、归档、视频和完整自主执行流程仍未完成。

## 更新与外部网络

连接公司入口会向该服务发送必要的网络请求。启用更新后，客户端登录时和运行期间通过公司服务检查 GitHub Releases，主动下载时由公司服务代理取得对应安装包。GitHub 可看到公司服务器的出口 IP、请求时间及标准请求元数据；公司 GitHub 读取令牌只保存在服务器，未分发给员工或写进安装包。直接访问公开仓库和下载页时，GitHub 按自己的政策处理访问数据。

应用代码没有接入广告、产品行为统计或远程崩溃上传服务，不向项目维护者集中上传聊天。Electron、操作系统以及管理员选定的第三方供应商可能有各自的联网行为和政策。当前不存在未经说明的后台训练、把员工聊天自动制作成公共 Skill 或自动公开公司数据的机制。

This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it. The configured company service, selected model providers, and enabled GitHub release checks described above are the network destinations requested by the user or operator.

## 管理、删除与反馈

员工可导出本地记录；删除本机应用数据前应先备份。公司数据、已提交 Skills、账号及模型配置的访问和保留由公司管理员按实际组织制度管理。用户反馈应先移除真实公司名称、密码、令牌、内部文件和聊天；敏感安全问题按 SECURITY.md 私下报告，不在公开 Issue 上传原始公司数据。
