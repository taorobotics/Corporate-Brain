## 2 实现原则

- 所有项目代码、设计和文档统一位于 D:/Open_Source_Project/Corporate Brain。
- 优先沿用 DSH 已有 Electron、React、TypeScript 和插件结构，先验证边界，减少对上游核心的修改。
- 公司后台采用可分模块的单体服务起步，不预先建设微服务集群；数据库、任务持久化和执行环境边界清晰。
- 共享前端组件和业务类型，员工桌面端与网页端使用不同的本地能力适配；管理后台共享视觉基础和服务端权限模型。
- 完整对话、个人项目与 Skill 草稿本地保存，按公司和员工账号隔离；共享项目配置与已提交 Skill 使用公司后端。不得先建设服务端聊天库，再用界面可见性代替本地存储要求。
- 网页端使用浏览器持久本地存储，不默认跨设备同步；本地记录导出导入与公司业务备份分别实现。模型网关只转发必要上下文，不记录完整请求响应正文。
- 账号、Skill 归属与分发按部门组织，每人独立账号；部门管理员和审核员分别授权。员工用户标识独立于部门，调部门不会重建本地记录空间。Skill 归属部门、发布受众和底层资料权限分别校验。
- 对话、图片、视频、MCP 和文件能力分别声明用途和协议，避免把所有接口都包装成同一种聊天请求。
- 未配置或无法验证的集成显示明确状态，测试替身与真实服务分开，不能以测试替身通过代替生产验收。
- 开发过程中持续更新本文件状态和任务记录，未执行验证不写通过。

## 3 阶段与交付关卡

### 阶段 A 技术验证与工程基础

| 任务 | 交付与通过条件 |
| --- | --- |
| A-01 核实 REA 与 DSH | 固定来源和版本，阅读实际接口，记录调查对象、可观察行为和局限 |
| A-02 DSH 集成验证 | 用最小会话完成一次真实工具调用和本地状态回放；验证本地运行、停止、错误及公司工具接入方式，核查其会话目录、遥测与日志不隐式上传聊天 |
| A-03 桌面和 Web 外壳 | 桌面运行、网页运行、共同导航、菜单、账号弹层、对话预览规则得到验证 |
| A-04 后端基础 | 服务配置、持久存储、首次管理员初始化、日志和环境变量示例；没有明文写死的生产凭据 |
| A-05 构建与检查 | Windows 可构建；macOS 的构建环境与待验证项明确；所选依赖锁定 |

技术验证失败时，记录具体阻塞和替代实现，不把仿制界面称为已集成 DSH。

### 阶段 B 账号 项目和共享服务

- 部门建立、负责人和获授权管理员；员工独立账号按部门单个或批量开通、导入预览、临时初始密码取用和分发状态、首次改密、登录、退出、撤销、重置、启停和调部门。
- 公司与部门管理员权限边界；批量开通不静默覆盖账号，部门管理员不能扩大自身授权，普通导出和审计不留密码。
- 桌面本地会话、消息、个人项目、附件和成果引用；公司和账号隔离、重启恢复、导出导入与去重。
- 网页端浏览器本地会话与草稿存储、数据丢失说明；桌面记录互通必须经过同机助手配对，首版默认不互通。
- 团队项目、成员、公共配置和明确共享资源使用服务端授权，本地对话关联不上传。
- 员工端、网页端和管理后台接同一套公司业务接口；不建设员工历史聊天集中上传或管理员浏览接口。
- 所有页面的导航、搜索、列表、表单、加载、空状态与错误状态。

关卡：两个员工分别操作，本地记录隔离、换设备不自动出现历史；部门账号开通与分发、管理员权限和调部门后的资源授权生效，不影响本地记录归属。对应 AC-01、AC-13、AC-14、AC-15、AC-19、AC-21、AC-22、AC-23、AC-26。

### 阶段 C 模型 媒体 本地文件和公司知识

- 公司和个人服务连接、脱敏密钥、能力选择、连接测试、默认服务和额度。
- 真实图片生成、参考图和多轮修改，视频异步任务、恢复与下载。
- 核查网关、代理、任务执行和错误追踪的持久化内容：只保留必要任务输入、状态、成果及用量；关闭模型请求响应正文日志，配置任务暂存清理。
- 本地助手、目录与全盘权限、文档解析、批量操作和实际落盘。
- NAS 来源、目录访问与资料过滤，检索引用、归档、离线恢复。

关卡：真实模型与 NAS 测试通过；任务超时、保存失败、撤权和离线可恢复。对应 AC-02 至 AC-08、AC-17。

### 阶段 D 对话转 Skills 到跨员工复用

- 本机来源选择和提炼，参数化、参考资源与工具依赖、本地草稿编辑；所选推理输入和最终发布材料分别预览。
- 用新输入试运行，明确选择提交文件、摘录和测试摘要，按清单打包冻结版本；内容与权限审查、退回与批准。
- 审核来源仅展示作者提交的包内摘录；不回连作者电脑，不上传聊天库或完整试运行对话。
- 私有技能仓库、可见范围、安装、升级、停用和回退。
- 部门归属、默认本部门发布、指定多个部门或全公司受众；部门审核权与公司发布权分开校验，扩大受众重新审核。
- 按部门检索、审核与推荐分发，员工确认安装；详情、旧版本和素材下载使用一致授权，调部门后刷新已安装技能状态，部门资源显式移交。
- 独立员工在另一台机器、新会话和新素材上的复用验证。

关卡：完成 A 员工到 B 员工的真实完整流程；不能携带 A 的密钥、绝对路径、完整聊天或额外资料权限。B 的运行记录落在 B 本机，跨部门分享与审核、调部门后的归属和失权生效。对应 AC-09 至 AC-12、AC-20、AC-24、AC-25、AC-26。

### 阶段 E 发布与交付

- Windows 和 macOS 的实际运行测试、菜单、文件权限、升级和卸载。
- 管理后台客户端发布、任务与用量、公司知识和系统配置。
- 备份恢复、安装部署、管理员操作、模型与 NAS 配置说明。
- 按最终效果图做视觉对照；运行核心自动化测试与端到端验收。

关卡：26 项首版验收逐项有证据。需要外部环境或签名条件的项目单列待完成，不能标记整套产品已投产。

## 4 服务接口与领域边界

| 边界 | 负责内容 |
| --- | --- |
| 组织账号与授权 | 部门、成员和调部门、分部门管理与审核授权、批量开通分发、初始密码与重置、登录会话、资源授权和策略变更 |
| 本地记录 | 桌面或浏览器本地会话、消息、个人项目、文件与成果关联、草稿、账号隔离和导出导入 |
| 共享项目 | 公司后端管理项目成员、公共上下文与明确共享资源；不保存员工聊天全文或本地会话索引 |
| 服务连接 | 密钥、适配器、能力、连接测试、默认模型、额度 |
| 执行与任务 | 本地和服务端执行路由、任务状态、重试核对、取消与恢复 |
| 知识与 NAS | 来源、解析、搜索、ACL 映射、引用和归档 |
| Skill 生命周期 | 本地草稿与完整试运行；服务端仅保存主动提交的包、部门归属、受众、测试摘要、版本、分范围审核、发布分发、移交与回退；员工本地安装运行 |
| 运营与交付 | 用量、审计、客户端版本、品牌配置、备份恢复 |

服务端资源 ID、用户与权限来自服务端事实，不直接信任前端传入的归属。后台接口和员工接口按角色授权，不能只做两个不同的网页入口。

## 5 开发开始前无需阻塞的工作

现阶段可以开展界面、数据结构、账号项目、协议适配层和自动化测试。真实 NAS、付费生成验收、macOS 实机和正式签名需使用业务方实际环境；这些依赖在 PRD 中登记，开发不能伪造其连接成功。
