## 当前发布

[v0.1.1 Release](https://github.com/taorobotics/Corporate-Brain/releases/tag/v0.1.1) 已发布为 Latest，包含统一下拉菜单更新、Windows x64 安装程序、Mac arm64 与 x64 DMG、公司服务器更新 ZIP、SHA-256 校验文件及各平台验证报告。四个包均来自标签指向的同一源码提交，已复核 GitHub 资源摘要与验证记录，见 [发布验证清单](../artifacts/releases/v0.1.1.json)。Windows 通过 20 项桌面检查，两种 Mac 各通过 19 项，并完成 DMG 挂载与打包程序首次启动检查；各构建均通过前端生产构建和 9 项后端测试。服务器包通过 ZIP 完整性检查，不包含公司数据或密钥。

首次工作流的四个平台构建均成功，发布阶段因草稿查询方式失败而取消；修复发布工具后，恢复工作流校验原构建的源码与任务结果，复用同一批产物完成发布，没有覆盖标签或重建产品包。Windows 仍未签名，Mac 为 ad-hoc 签名，员工物理设备的安装、升级与卸载仍待验收。下表中的 v0.1.0 打包记录保留为历史证据。后续每批完整更新依照 [发布规则](RELEASE-POLICY.md) 递增版本并发布 Release。

## 仍未完成，按此顺序继续

1. 把 DSH 接入员工的实际规划和执行流程，落实目录或全盘模式、插件能力、进程权限、停止和错误恢复；目前只有 SDK 启动验证，不能视为已完成 Agent 执行。个人连接安全存储、模型能力发现、Anthropic 和更多协议也未实现。
2. 使用业务方配置的对话和图片凭据验证真实调用，补参考图与连续改图、流式回复、停止、输出规格和失败恢复。当前没有真实生成验收结果。
3. 实现 Seedance 等实际视频供应商的持久任务、查询、取消、幂等、恢复和下载；目前视频入口明确显示未接通，没有提交或扣费。
4. 根据实际 NAS 的协议、地址和 ACL 实现连接、文档解析、授权检索、来源、归档及撤权刷新；当前公司知识只是接入状态，不是已实现知识库。
5. 补团队项目、项目上下文和文件技能关联、共享资源依赖校验、技能版本族、差异和回退、部门推荐分发、已安装失权标记、归属移交和更完整的编辑维护。现有本地个人项目不能当作已实现团队项目。
6. 补离线冷启动与本地解锁、用户设置保存位置、多格式及大文件解析、后台运行、正式更新部署与覆盖安装验收、备份恢复演练、额度并发和任务用量。客户端检查和下载链路已实现；当前服务不可达时展示重新连接，没有假装支持完整离线启动。
7. Mac 员工物理设备的下载、Gatekeeper、原生菜单和文件权限、安装升级卸载验证；Windows 安装升级卸载验证；正式签名、公证、公司部署、压测和 PRD 26 项完整验收。Mac 原生 CI 构建、桌面交互与打包程序首次启动已通过，不能替代上述员工设备验收。

后续真实集成所需：模型服务地址、实际模型 ID 与开通能力（密钥在后台填写），视频接口与额度，NAS 品牌协议、内网目录和账号权限，部门与员工名单，实际公司 HTTPS 入口，以及 Mac 实机和签名条件。缺少这些参数不影响继续编码，但真实集成不能标记通过。
