# 开发状态与验证记录

版本：v0.2.8 测试版。更新日期：2026-10-27。完整需求以 PRD v0.3 为准，未宣布 26 项首版验收全部通过。

## 当前发布

[v0.2.8 Release](https://github.com/taorobotics/Corporate-Brain/releases/tag/v0.2.8) 将沿用 Windows 四步安装向导、两种 Mac 安装包和服务器更新包，并加入员工端预置公司入口。员工包只读取安装资源中的 URL，账号、密码、密钥不进入安装包；没有设置 `BRAIN_APP_URL` 的测试包显示联系管理员提示。安装器准备、写入、注册和完成检查前会立即刷新进度页，写入阶段文案与实际动作一致。macOS 首次启动验证已同步“公司大脑未配置”页面。Windows 和 Mac 资源、校验和真实发布报告在 GitHub Actions 完成后补充到发布清单。

v0.2.2 及更早 Release 和验证清单继续保留。v0.2.1 因 Mac Electron 许可位置检查失败，保留为未发布候选，未移动旧标签或替换旧包。Windows 安装生命周期验证运行于临时 runner；Windows 仍未签名，Mac 为 ad-hoc，员工物理设备与企业安全策略、可信签名仍待验收。

[原开源审查记录](../artifacts/open-source-readiness.json)保留 v0.2.2 时的 15 次提交与旧包检查；本版另用 Gitleaks 8.30.1 扫描全部本地引用可达的 26 次提交，没有发现，见 [源码扫描记录](../artifacts/installer-source-scan.json)。GitHub 识别为 MIT，仓库仍为 Private。公开授权、账号 MFA、SignPath 注册与申请审核仍需维护者和服务方完成；许可证、声明与申请模板不代表已获签名批准。
