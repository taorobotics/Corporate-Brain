| 模块 | 实现内容 |

| 公司模型 | 自定义 API 前缀、密钥、实际模型标识、用途与获准部门；密钥服务端加密、脱敏返回；OpenAI 兼容文本与基础图片调用；未配置和真实错误明确展示 |
| 桌面文件 | 系统文件和目录选择、受支持小文本与图片附件读取、原生保存对话框；公司服务器连接页与地址切换；未开放任意 shell 或伪造全盘访问 |

2. 使用业务方配置的对话和图片凭据验证真实调用，补参考图与连续改图、流式回复、停止、输出规格和失败恢复。当前没有真实生成验收结果。
3. 实现 Seedance 等实际视频供应商的持久任务、查询、取消、幂等、恢复和下载；目前视频入口明确显示未接通，没有提交或扣费。
4. 根据实际 NAS 的协议、地址和 ACL 实现连接、文档解析、授权检索、来源、归档及撤权刷新；当前公司知识只是接入状态，不是已实现知识库。
5. 补团队项目、项目上下文和文件技能关联、共享资源依赖校验、技能版本族、差异和回退、部门推荐分发、已安装失权标记、归属移交和更完整的编辑维护。现有本地个人项目不能当作已实现团队项目。
6. 补离线冷启动与本地解锁、用户设置保存位置、多格式及大文件解析、后台运行、更新分发、备份恢复演练、额度并发和任务用量。当前服务不可达时展示重新连接，没有假装支持完整离线启动。
7. Mac 员工物理设备的下载、Gatekeeper、原生菜单和文件权限、安装升级卸载验证；Windows 安装升级卸载验证；正式签名、公证、公司部署、压测和 PRD 26 项完整验收。Mac 原生 CI 构建、桌面交互与打包程序首次启动已通过，不能替代上述员工设备验收。

后续真实集成所需：模型服务地址、实际模型 ID 与开通能力（密钥在后台填写），视频接口与额度，NAS 品牌协议、内网目录和账号权限，部门与员工名单，实际公司 HTTPS 入口，以及 Mac 实机和签名条件。缺少这些参数不影响继续编码，但真实集成不能标记通过。
