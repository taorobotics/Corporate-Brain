# Contributing

Original contributions are accepted under this repository's MIT license. Keep third-party copyright notices and comply with each dependency's original license. Do not submit copied proprietary application code, internal company Skills, user data, credentials, private model endpoints or signed binaries built outside the reviewed workflow.

Use synthetic examples and temporary test databases. Keep unrelated local changes intact. Before submitting, run npm test, npm run build and any relevant desktop checks. Changes affecting release packaging must preserve the package file allowlist, legal notices, exact source version and SHA-256 evidence. See AGENTS.md and docs/RELEASE-POLICY.md.

External pull requests and changes to workflows, dependencies, privileges and signing policies require maintainer review. Contributors with repository or signing privileges must use MFA. SignPath production approvals, when the project is admitted, are separate human approvals and cannot be bypassed by release automation.
